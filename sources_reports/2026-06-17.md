### 1. GitHub Multilingual Repositories Dataset

- **链接**: https://github.com/github/multilingual-repositories
- **语言覆盖**: 多语言（覆盖 40M+ 公开仓库的非英语内容，README/Issue/PR 语言分类）
- **数据规模**: 40M+ 仓库元数据，80M+ 语言分类行
- **许可协议**: CC0-1.0（公共领域）
- **类别**: 预训练
- **发现日期**: 2026-06-17
- **最后更新**: 2026-06-15（2 天前）
- **时效性**: 高
- **描述**: GitHub 于 2026 年 6 月 15 日正式发布的仓库级多语言元数据集。包含超过 4000 万个公开仓库的元数据，以及超过 8000 万行语言分类信号（来自 README 文件、Issue 讨论和 Pull Request 内容）。旨在帮助研究人员和开发者发现非英语的多语言开发者内容，填补非英语代码协作语境的数据空白。CC0-1.0 公共领域许可，可自由用于 LLM 训练和评测。Microsoft 2025 年开源 AI 多语言数据承诺的落地项目。
- **优缺点分析**:
  - ✅ **CC0-1.0** 公共领域许可——所有数据集中许可最开放的之一
  - ✅ **40M+ 仓库**规模惊人，覆盖范围远超此前任何代码域数据集
  - ✅ GitHub 官方发布，数据质量和持续维护有强保障
  - ✅ 填补非英语代码协作语境的数据空白，独特性极强
  - ⚠️ 数据为仓库元数据和语言分类信号，非原始代码文本——对代码 LLM 训练需二次提取
  - ⚠️ 新发布（v1），社区验证和下游应用案例尚需积累
- **推荐优先级**: ⭐⭐⭐⭐⭐ — 强烈推荐
- **推荐判断**: ✅ **强烈推荐入榜 Top 10**。理由：(1) CC0-1.0 许可使其成为所有数据集中商用最友好的；(2) 40M+ 仓库覆盖是当前代码域多语言数据的数量级突破；(3) GitHub 官方背书确保长期维护。**建议替换 MGSM**（250 道题 × 11 语言，规模小且社区已有更好替代品如 multilingual-gsm-symbolic）或 **Common Corpus**（Mozilla 版，500B words 但 4 年未更新）。如已在 06-14 报告中将 Ultra-FineWeb-L3 替换了 RedPajama-V2，则建议替换 MGSM

### 2. DetectRL-X

- **链接**: https://github.com/AIDC-AI/Marco-LLM/tree/main/DetectRL-X
- **语言覆盖**: 8 种语言（覆盖多个语系）
- **数据规模**: 3.46M 样本（346 万），6 个领域，4 种商业 LLM 生成器，8 种攻击策略，4 种文本长度粒度
- **许可协议**: 开放获取（ACL 2026）
- **类别**: 评估
- **发现日期**: 2026-06-17
- **最后更新**: 2026-05-18
- **发布版本**: v2 (arXiv:2605.15518v2)
- **时效性**: 高
- **描述**: ACL 2026 收录的最大规模多语言 LLM 生成文本检测基准。覆盖 8 种常用商业语言、6 个高风险领域（学术/新闻/小说/SEO/Wiki/WebText）、4 种商业 LLM 生成器、8 种攻击策略（含改写和扰动攻击）、3 种文本精炼操作。支持并行二元/三元检测任务，包含 8 个评估维度并比较 12 种检测器。首次系统性评估检测器在多语言真实场景下的可靠性。AIDC-AI/Marco-LLM 项目发布。
- **优缺点分析**:
  - ✅ **ACL 2026** 收录，顶级学术认可
  - ✅ **3.46M 样本**——当前最大规模多语言 AI 文本检测基准
  - ✅ 8 种攻击策略 + 4 种 LLM 生成器，评估维度极全面
  - ✅ 首次系统性评估多语言场景下检测器可靠性，开创性强
  - ⚠️ 仅 8 种语言，语言覆盖偏窄
  - ⚠️ 检测任务较为专一，非通用评估基准
- **推荐优先级**: ⭐⭐⭐⭐ — 高推荐
- **推荐判断**: ✅ 推荐 — 如构建多语言 AI 内容检测/安全系统，此为当前最强基准。与基线中 MULTITuDE（11 语言 AI 文本检测）形成互补：MULTITuDE 覆盖更广，DetectRL-X 规模和攻击维度更强
