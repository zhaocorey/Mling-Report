## 🔄 更新数据集

> 已知数据集发生版本/规模/内容变化（3 个）

### 1. HPLT 3.0 (HPLT/HPLT3.0)

- **变更摘要**: 2026-07-08 数据集页面刷新。HPLT 3.0 当前明确为 **50TB 压缩数据**，覆盖 **198 种语言**，非英语部分约 **13.5 万亿 tokens / 11.5 billion 文档**。数据来源于 Internet Archive + Common Crawl（2012-2024），约为前一版本的 **3 倍**。使用 Trafilatura 文本提取 + OpenLID 2.0 语言识别 + Monotextor pipeline 去重过滤。
- **上次更新**: 2026-06-11 → **当前更新**: 2026-07-08
- **变更影响**: HPLT 3.0 作为当前最大开放多语言预训练语料的地位进一步巩固。50TB / 13.5T tokens 的规模使其在预训练数据集中居于第一梯队。推荐优先级维持 ⭐⭐⭐⭐⭐。

### 2. multilingual-gsm-symbolic

- **变更摘要**: 2026-07-20 数据集内容更新，下载量从 540 增长至 781（+44%）。该数据集基于 GSM-Symbolic 方法扩展到多语言（ar/en/da/de/fr/is/no/zh），评估 LLM 的数学推理鲁棒性。
- **上次更新**: 2026-06-15 → **当前更新**: 2026-07-20
- **变更影响**: 下载量增长反映社区关注度上升。作为多语言数学推理评估的独特基准（符号化变体测试鲁棒性），推荐优先级维持 ⭐⭐⭐⭐。

### 3. HPLT OpenLID-v3

- **变更摘要**: 2026-06-18 更新，训练数据扩展至 **137M 行**，覆盖 **39 种语言/脚本类别** 和 **21 种数据来源**。是 HPLT 3.0 pipeline 中的核心语言识别组件。
- **上次更新**: 2026-06-18（首次发现）→ **当前更新**: 2026-06-18
- **变更影响**: OpenLID-v3 作为开源语言识别工具，对多语言数据处理 pipeline 有实用价值。归类为工具/辅助数据集。
