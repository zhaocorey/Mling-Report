## 🏆 高价值数据集详解

按语教授评估标准，以下数据集值得重点关注：

### ⭐ Tier 1 — 强烈推荐

#### 1. Iman998/HexaBee-Multilingual-SFT

| 属性 | 详情 |
|------|------|
| 规模 | **19.4M 样本**（6 语言） |
| 语言 | fa, en, ar, zh, he, es |
| 许可证 | other（需查看具体条款） |
| 配套论文 | arXiv:2610.16361 |

**教授评估**：本轮最具价值的数据集。22 个 SFT 导出覆盖 QA、翻译、文本生成，采用**双向监督**方法在 6 种类型学多样化语言间构建。波斯语(fa)和希伯来语(he)在高质量 SFT 数据中极为稀缺。有论文支撑意味着数据质量经过同行评审。

**适用场景**：多语言 SFT 训练、翻译模型、跨语言 QA
**风险**：许可证标注为 "other"，使用前需确认具体条款

#### 2. ketanmore/LLaVA-Instruct-150K-13-African-Languages

| 属性 | 详情 |
|------|------|
| 规模 | 150K 指令样本 |
| 语言 | 13 种非洲语言（am, ha, ln, st, zu 等） |
| 许可证 | unknown |

**教授评估**：将经典的 LLaVA-Instruct-150K 翻译到 13 种非洲语言，是一个**里程碑级**的多模态指令微调资源。阿姆哈拉语(am)、豪萨语(ha)、林加拉语(ln)等在多模态数据中几乎完全空白。虽然翻译质量需要抽查验证，但覆盖本身已是突破。

**适用场景**：非洲语言多模态模型微调、视觉 QA
**风险**：机器翻译质量未知；许可证不明

#### 3. years0/multilingual-code-switching-bench

| 属性 | 详情 |
|------|------|
| 语言 | en, ar, zh, es + 多种混合变体 |
| 许可证 | MIT ✅ |
| 覆盖变体 | Franco-Arabic/Arabizi, Singlish, Taglish, Hinglish, Naija Pidgin, Sheng |

**教授评估**：代码切换是真实世界多语言使用的核心场景，但评估基准极度稀缺。本数据集覆盖了从新加坡英语(Singlish)到尼日利亚皮钦语(Naija Pidgin)等**真实世界变体**，MIT 许可证友好。对评估模型在实际多语言环境中的表现至关重要。

**适用场景**：评估 LLM 对非标准/混合语言的鲁棒性
**风险**：样本量较小（<1K）

### ⭐ Tier 2 — 值得关注

#### 4. fai-adh/fon-code-switching-evaluation
- **亮点**：法语-丰语(Fon)代码切换，丰语是贝宁的低资源语言
- **价值**：填补西非语言评估空白，MIT 许可证
- **关注原因**：测试模型在关键信息以低资源语言呈现时的理解能力

#### 5. RayNene/qwen3-multilingual-safety-eval
- **亮点**：英语/斯瓦希里语/基库尤语的安全评估
- **价值**：非洲语言安全评估几乎空白，CC-BY-4.0 许可证
- **关注原因**：安全评估从主流语言向低资源语言扩展的重要一步

#### 6. psdn-ai/CROWS-multilingual
- **亮点**：ar, de, en, es, fr 五语言基准，3217 下载量

- **关注原因**：可作为跨语言评估的标准化基准

- **关注原因**：专业领域 + 跨语言 = 高应用价值

#### 8. KeisukeMiyamoto/lambda-audio-courpus-multilingual
- **亮点**：大规模多语言音频语料（10 月发布）
- **价值**：多语言 ASR/TTS 训练数据始终稀缺

## 📈 趋势观察

### 1. 🔄 代码切换评估成为新范式

本轮 **6 个数据集**（30%）专门针对代码切换场景，涵盖：
- 文本代码切换（Arabizi, Singlish, Taglish, Hinglish, Naija Pidgin, Sheng）
- 语音代码切换（EN-HE, EN-DE, Syrian Arabic-EN）
- 法语-低资源语言切换（FR-Fon）

**洞察**：社区正在从「标准语言评估」向「真实世界混合语言评估」转变。这反映了全球多语言用户的真实使用模式——人们在对话中频繁切换语言。

### 2. 🛡️ 安全评估向低资源语言扩展

3 个安全评估数据集覆盖了：
- 斯瓦希里语 + 基库尤语（东非）
- 阿拉伯语 + 法语（北非/中东）
- 英语 + 孟加拉语（南亚灾害场景）

**洞察**：AI 安全不再是英语专属关注点。随着 LLM 在全球部署加速，低资源语言的安全评估成为刚需。

### 3. 📊 评估 > 训练（本轮）

评估类数据集占比 55%，训练类仅 25%。这与社区趋势一致：
- 模型架构趋于稳定，评估框架需要跟上
- 多语言评估标准尚未统一，各方在探索
- 专业化评估（法律、安全、灾害、代码切换）填补空白

### 4. 🎵 希伯来语代码切换集群

3 个希伯来语相关数据集（HexaBee + EN-HE 句子语料 + EN-HE ASR 基准）形成一个小型集群，说明希伯来语-英语代码切换正在受到系统性关注。
