### 1. Math-PT — Portuguese Math Reasoning Benchmark 📄

- **链接**: https://arxiv.org/abs/2604.25926
- **语言覆盖**: pt（欧洲葡萄牙语 + 巴西葡萄牙语）
- **数据规模**: 1,729 道数学推理题
- **许可协议**: 研究用（论文）
- **类别**: 评估基准
- **发现日期**: 2026-07-11
- **最后更新**: 2026-04-25
- **时效性**: 高
- **版本**: v1
- **描述**: 面向欧洲葡萄牙语和巴西葡萄牙语的数学推理基准。从葡萄牙和巴西的本土来源（奥数竞赛、考试等）精选，包含选择题、开放题和图形题。解决现有数学基准中的语言偏见问题——绝大多数基准以英语为中心，葡萄牙语使用者被迫用第二语言测试推理能力。
- **优缺点分析**:
  - ✅ **双变体覆盖**——同时覆盖欧洲葡萄牙语和巴西葡萄牙语，反映语言多样性
  - ✅ **本土来源**——非翻译产品，直接从葡语国家的竞赛/考试精选
  - ✅ 多种题型（MCQ + 开放题 + 图形题），评估维度丰富
  - ⚠️ 单一语言（葡萄牙语），通用性受限
  - ⚠️ 1,729 道题规模中等
- **推荐优先级**: ⭐⭐⭐⭐ — 葡萄牙语数学推理的稀缺基准
- **推荐判断**: ✅ 推荐 — 填补基线中葡萄牙语推理评估空白（基线中仅有 MGSM 含少量葡语）

### 2. ML-Bench&Guard — Policy-Grounded Multilingual Safety Benchmark 📄

- **链接**: https://arxiv.org/abs/2605.00689
- **语言覆盖**: 多语言（具体语言数待确认）
- **数据规模**: 基于策略规则的多语言安全基准
- **许可协议**: 研究用（论文）
- **类别**: 评估基准/安全
- **发现日期**: 2026-07-11
- **最后更新**: 2026-05-01
- **时效性**: 高
- **版本**: v1
- **描述**: 策略驱动的多语言安全基准和护栏模型。不同于传统的二元安全分类，ML-Bench&Guard 基于具体策略规则评估模型安全行为，对 Nemotron 等安全模型进行系统基准测试。为多语言安全评估提供策略化、细粒度的方法论。
- **优缺点分析**:
  - ✅ **策略驱动**——超越简单二元分类，更贴近真实部署场景的安全评估需求
  - ✅ **多语言覆盖**——安全评估不局限于英语
  - ✅ 与 CultureGuard、RefusEU 等形成安全评估矩阵
  - ⚠️ 具体语言覆盖和数据规模待确认（仅论文可用）
  - ⚠️ 尚无 HF 数据集发布
- **推荐优先级**: ⭐⭐⭐⭐ — 策略化安全评估的方法论创新
- **推荐判断**: ✅ 推荐 — 与基线中 CultureGuard、iNLP-Lab/multilingual-safety 互补，增强安全评估维度

### 3. SEADialogues — Southeast Asian Culturally Grounded Dialogue Dataset 📄

- **链接**: https://arxiv.org/abs/2508.07069
- **语言覆盖**: 8 种东南亚语言（来自 6 个国家）
- **数据规模**: 多轮对话数据集，含角色属性和文化话题
- **许可协议**: 研究用（论文）
- **类别**: 微调/对话
- **发现日期**: 2026-07-11
- **最后更新**: 2026-06-01
- **时效性**: 高
- **版本**: v1
- **描述**: 以东南亚文化为基础的多轮对话数据集。覆盖 6 个东南亚国家的 8 种语言，其中多种为低资源语言。每段对话包含角色属性（persona）和文化扎根话题，反映日常东南亚生活场景。推进文化感知 LLM 对话研究。
- **优缺点分析**:
  - ✅ **8 种东南亚语言**——多种低资源语言首次出现在对话数据集中
  - ✅ **文化扎根**——非翻译产品，直接反映东南亚日常生活
  - ✅ 角色属性标注——支持 persona-grounded 对话生成研究
  - ✅ 2026 年 6 月更新，时效性高
  - ⚠️ 论文阶段，HF 数据集发布待确认
  - ⚠️ 对话数据质量评估框架待建立
- **推荐优先级**: ⭐⭐⭐⭐ — 东南亚低资源语言对话数据的重要突破
- **推荐判断**: ✅ 推荐 — 与基线中 OpenSeal CPT Data (SEA-PILE-v2)、SEA-NLI 形成东南亚语言生态

- **许可协议**: NVIDIA 许可证
- **类别**: 合成数据/预训练
- **发现日期**: 2026-07-11
- **最后更新**: 2026-06-01
- **时效性**: 高
- **版本**: v1
- **描述**: NVIDIA 发布的多语言、地区特定合成人物画像数据集集合。每个地区数据集（如 Nemotron-Personas-Korea）与官方人口统计数据（KOSIS 等）对齐，用于文化扎根的数据生成。支持主权 AI 发展——各国可基于本地化人物画像生成符合本地文化的训练数据。
- **优缺点分析**:
  - ✅ **NVIDIA 官方发布**——工业级品质，已有多个地区版本

  - ✅ 每个地区 1M+ 画像，规模庞大
  - ⚠️ NVIDIA 许可证，商用可能有限制
  - ⚠️ 合成数据，需验证生成质量

- **推荐判断**: ✅ 推荐 — 主权 AI 和文化扎根数据生成是 2026 年热点方向

### 5. DimABSA — Multilingual Dimensional ABSA (SemEval-2026) 📄

- **链接**: https://arxiv.org/abs/2601.23022
- **语言覆盖**: en, es, zh, ar, hi, de（6 种语言）
- **数据规模**: 76,958 个方面实例，42,590 条句子，4 个领域
- **许可协议**: 研究用（SemEval-2026 Task 3）
- **类别**: 评估基准/微调
- **发现日期**: 2026-07-11
- **最后更新**: 2026-01-30
- **时效性**: 中
- **版本**: v1 (SemEval-2026)
- **描述**: 首个多语言维度方面级情感分析（ABSA）资源。不仅标注传统 ABSA 元素（方面词、情感极性），还标注连续效价-唤醒度（valence-arousal）分数。引入连续 F1 指标，弥合传统分类式 ABSA 与维度情感分析之间的鸿沟。SemEval-2026 Task 3 吸引了 300+ 参赛者。
- **优缺点分析**:
  - ✅ **首创性**——首个将维度情感引入多语言 ABSA 的资源
  - ✅ **SemEval-2026**——共享任务背书，300+ 参赛者验证
  - ✅ **6 语言 × 4 领域**——跨语言跨领域泛化性评估
  - ✅ 连续 F1 指标——方法论创新
  - ⚠️ 发布于 1 月，距今 6 个月，接近陈旧阈值
  - ⚠️ 任务特定（ABSA），通用性有限
- **推荐优先级**: ⭐⭐⭐⭐ — 多语言情感分析的重要基准
- **推荐判断**: ✅ 推荐 — 填补基线中多语言细粒度情感评估的空白

### 6. UrduBench — Urdu Reasoning Benchmark 📄

- **链接**: https://arxiv.org/abs/2601.21000
- **语言覆盖**: ur（乌尔都语）
- **数据规模**: MGSM + MATH-500 + CommonSenseQA + OpenBookQA 翻译为乌尔都语
- **许可协议**: 研究用（代码和数据将发布）
- **类别**: 评估基准
- **发现日期**: 2026-07-11
- **最后更新**: 2026-01-28
- **时效性**: 中
- **版本**: v1
- **描述**: 乌尔都语推理基准，采用上下文集成翻译 + 人工验证流程。将 4 个主流推理基准（MGSM、MATH-500、CommonSenseQA、OpenBookQA）翻译为乌尔都语，评估推理和指令微调 LLM 在多种提示策略下的表现。揭示乌尔都语在多步骤推理和符号推理中的重大挑战。
- **优缺点分析**:
  - ✅ **4 个基准合一**——全面评估数学/常识/科学知识推理
  - ✅ **人工验证**——翻译质量有保障
  - ✅ 乌尔都语是全球第 10 大语言（2.3 亿使用者），但 NLP 资源极度匮乏
  - ⚠️ 翻译基准的固有局限——文化适应性可能不足
  - ⚠️ 发布于 1 月，距今 6 个月
- **推荐优先级**: ⭐⭐⭐⭐ — 乌尔都语推理评估的里程碑
- **推荐判断**: ✅ 推荐 — 乌尔都语是南亚最重要的低资源语言之一，填补基线空白

### 9. Soohak — Research-level Math Benchmark 📄

- **链接**: https://arxiv.org/abs/2605.09063
- **语言覆盖**: en（研究级数学，语言非主要维度）
- **数据规模**: 439 道题（64 位数学家原创）
- **许可协议**: 2026 年末公开发布
- **类别**: 评估基准
- **发现日期**: 2026-07-11
- **最后更新**: 2026-05-13
- **时效性**: 中
- **版本**: v1 (pre-release)
- **描述**: 由 64 位数学家从零原创的研究级数学基准。前沿模型表现：Gemini-3-Pro 30.4%、GPT-5 26.4%、Claude-Opus-4.5 10.4%。创新引入「拒绝子集」(Refusal Subset)——测试模型识别不当定义问题的能力，无模型超过 50%。数据集将于 2026 年末发布。
- **优缺点分析**:
  - ✅ **数学家原创**——非现有题目汇编，确保新颖性和难度
  - ✅ **拒绝子集**——评估模型「知道自己不知道什么」的能力，方法论创新
  - ✅ 前沿模型远低于 50%，区分度极高
  - ⚠️ 以英语为主，非多语言数据集
  - ⚠️ 数据尚未公开发布
- **推荐优先级**: ⭐⭐⭐ — 研究级数学推理的前沿基准
- **推荐判断**: ⚠️ 有条件推荐 — 虽以英语为主，但拒绝子集方法论可迁移至多语言场景

> 以下 9 个数据集此前通过手动补录/漏检复盘加入基线，但从未在历史报告🆕章节正式介绍。本次集中补录。

### 1. PolyMath — 多语言数学推理基准 (NeurIPS 2025 D&B)

| 属性 | 值 |
|------|------|
| **来源** | Qwen 团队 |
| **URL** | https://huggingface.co/datasets/Qwen/PolyMath |
| **论文** | https://arxiv.org/abs/2504.18428 |
| **语言** | 18 种语言 × 4 个难度级别 |
| **规模** | 9,000 道高质量数学题 |
| **许可证** | Apache-2.0 |
| **发现日期** | 2025-04-18 |
| **时效性** | 中（经典基准，持续被引用） |

Qwen 团队发布的多语言数学推理基准，NeurIPS 2025 Datasets & Benchmarks Track 收录。覆盖 18 种语言、4 个难度级别（从小学数学到竞赛级），确保难度层次、语言多样性和翻译质量。是当前多语言数学推理评估的核心参考基准，PluraMath 为其低资源语言扩展版。

### 2. PluraMath — PolyMath 低资源语言扩展 ⭐

| 属性 | 值 |
|------|------|
| **来源** | TUM NLP |
| **URL** | https://huggingface.co/datasets/tum-nlp/PluraMath |
| **论文** | https://arxiv.org/abs/2607.05992 |
| **语言** | 18 种低资源语言（6 个语系），含 Hindi、Turkish、Upper/Lower Sorbian |
| **规模** | 18 语言 × 500 样本 = 9,000 样本 |
| **许可证** | Apache-2.0 |
| **发现日期** | 2026-07-07 |
| **时效性** | 高 |

将 PolyMath 扩展至 18 种此前未被充分覆盖的低资源语言，包括 Upper/Lower Sorbian（不足 15K 母语者的极危语言）。采用 human-curated 翻译验证 pipeline，由母语者逐条校验预计算翻译。配套评估 27 个推理 LLM（涵盖 small/mid/large/closed-source 四种规模），确认高资源与低资源语言间的数学推理性能差距持续存在。**完全开源数据集、数据获取 pipeline 和评估框架**。

### 3. MMATH — 多语言复杂数学推理基准

| 属性 | 值 |
|------|------|
| **来源** | 学术论文 |
| **URL/论文** | https://arxiv.org/abs/2505.19126 |
| **语言** | 10 种语言 |
| **规模** | 374 道高质量数学题 |
| **发现日期** | 2025-05-19 |
| **时效性** | 中 |

针对 MGSM 等简单数学任务在评估先进推理 LLM 时区分度不足的问题，构建了覆盖 10 种语言的 374 道复杂数学题。题目类型涵盖代数、几何、概率等，难度显著高于 MGSM，更适合评估 o1/o3 级别推理模型的多语言数学能力。

### 4. MGSM-Pro — MGSM 鲁棒性扩展版

| 属性 | 值 |
|------|------|
| **来源** | 学术论文 |
| **论文** | https://arxiv.org/abs/2601.21225 |
| **语言** | 多语言（MGSM 覆盖范围） |
| **发现日期** | 2026-01-21 |
| **时效性** | 高 |

引入 GSM-Symbolic 方法，为 MGSM 每道题生成 5 种变体（数字变化、人名变化、无关上下文注入等），测试模型对表面变化的鲁棒性。关键发现：低资源语言在数字变化时性能下降幅度远大于英语，暴露了多语言推理中的脆弱性问题。

### 5. HRM8K — 英韩双语数学推理基准 (8,011 题)

| 属性 | 值 |
|------|------|
| **来源** | 学术论文 |
| **论文** | https://arxiv.org/abs/2501.02448 |
| **语言** | 英语、韩语 |
| **规模** | 8,011 道题 |
| **发现日期** | 2025-01-02 |
| **时效性** | 中 |

配套 UST (Understand-Solve-Translate) 方法的英韩双语数学推理基准。核心贡献：通过对照实验发现多语言数学推理的性能差距**主要源于语言理解能力，而非推理能力本身**。为后续多语言推理优化提供了明确方向——优先提升低资源语言理解而非推理链设计。

### 6. FineTranslations — 万亿级多语言→英语平行数据

| 属性 | 值 |
|------|------|
| **来源** | HuggingFace FineWeb 团队 |
| **URL** | https://huggingface.co/datasets/HuggingFaceFW/finetranslations |
| **语言** | 500+ 种语言 → 英语 |
| **规模** | 万亿 token 级 |
| **发现日期** | 2026-06-17 |
| **时效性** | 高 |

基于 FineWeb-2 语料库，使用 Gemma3 27B 将非英语内容翻译为英语，构建的大规模多语言平行文本数据集。填补了大规模多语言翻译训练数据的空白，是当前最大规模的开源多语言平行数据集之一。17,521 次下载，294 个赞。**Top 10 候选**（替换 FineTranslations 陈旧化问题——自身即是被替换对象的原始版本）。

### 7. LEMAS Dataset — 最大开源多语言语音语料库

| 属性 | 值 |
|------|------|
| **来源** | Idea 研究院 |
| **URL** | https://huggingface.co/LEMAS-Project |
| **论文** | https://arxiv.org/abs/2601.04233 |
| **语言** | 10 种主要语言（中/英/德/法/西/葡/意/俄/印尼/越南） |
| **规模** | 150,000+ 小时，带词级时间戳 |
| **发现日期** | 2026-06-17 |
| **时效性** | 高 |

当前最大规模的开源多语言语音语料库，带有精确的词级时间戳标注。配套两个基准模型：LEMAS-TTS（流匹配 TTS）和 LEMAS-Edit（自回归语音编辑）。通过高效数据处理 pipeline 确保大规模数据的质量和标注精度。对多语言语音合成和识别研究具有重要参考价值。

## 🔍 本次专题观察

### 1. 数学推理数据集中爆发

本次增量中包含 **4 个数学相关数据集**（Math-PT、Soohak + 已报告的 MathNet、mAceReason-Math），加上基线中已有的 MGSM、PolyMath、PluraMath、MMATH、DAPO-Math-Multilingual-6Lang 等，数学推理已成为基线中覆盖最密集的任务领域之一。但需注意：大多数数学基准以英语为中心，非英语版本多为翻译产品，**Math-PT 和 MathNet 的本土化方法值得借鉴**。

### 2. 安全评估从二元分类走向策略化/维度化

ML-Bench&Guard（策略驱动）+ DimABSA（连续维度情感）+ RefusEU（拒绝对齐）三者共同指向一个趋势：**2026 年的安全/对齐评估正在从简单的「安全/不安全」二元标签走向更精细的维度化、策略化评估**。这对多语言场景尤为重要——不同语言和文化中的安全边界本就不同，二元标签无法捕捉这种复杂性。

### 3. 低资源语言评估基准涌现

UrduBench（乌尔都语）+ Math-PT（葡萄牙语双变体）+ SEADialogues（8 种东南亚语言）反映了社区的明确努力：**为高使用者但低 NLP 资源的语言构建专项评估基准**。这与基线中已有的非洲语言数据（multi-open、LughaGen）形成全球南半球语言覆盖的互补。

### 4. NVIDIA 数据生态持续扩张

Nemotron-CC-v2 + Nemotron-Personas + Nemotron-SFT-Multilingual-v2 + Nemotron-CC-Math + Nemotron-Safety-Guard-Dataset-v3——基线中已有 **5+ 个 NVIDIA 数据集**。NVIDIA 正在从硬件供应商转型为 AI 数据基础设施提供商，其数据集生态已形成从预训练到 SFT 到安全评估的完整链条。
