#### 1. hafsteinn/bfcl-v3-multilingual — 多语言函数调用评估基准 v3
- **最后更新**: 2026-09-28 | **时效**: 高
- **语言**: 多语言（含丹麦语等欧洲语言）
- **规模**: 512 下载

- **描述**: Berkeley Function Calling Leaderboard v3 (BFCL-v3) 的多语言适配版本。评估 LLM 在多语言环境下的函数/工具调用能力，包含简单调用、多函数选择、并行调用和无关函数识别四类任务，附带验证过的标准答案。
- **关联说明**: 与已报告的 `Multilingual-BFCL` 为同一基准的不同版本。v3 为 Berkeley 方面的最新迭代，评测任务设计更贴近真实 Agent 场景。

#### 2. Multilingual-NLP/YUE-PUB-Speech — 粤语语用理解基准 (Interspeech 2026) 🔥
- **最后更新**: 2026-09-28 | **时效**: 高
- **语言**: 粤语 (Cantonese)
- **规模**: 1,680 条音频样本
- **来源**: [HuggingFace](https://huggingface.co/datasets/Multilingual-NLP/YUE-PUB-Speech)
- **描述**: Interspeech 2026 录用的粤语语用理解基准。包含说话人识别和话语级分类任务，测试模型对粤语语用含义（如暗示、礼貌策略、语境推断）的理解能力。
- **意义**: 顶会品质保证。粤语作为全球约 8500 万人使用的主要方言，在 LLM 语音理解评估中长期被忽视。该基准填补了粤语语音语用评估的空白，对粤语 ASR + LLM 管线有直接价值。
- **推荐指数**: ⭐⭐⭐⭐（Interspeech 2026 录用，学术价值高）

## 🔭 趋势观察

### 1. 🏥 医学领域多语言 SFT 数据密集涌现
本轮 9 个数据集中有 2 个为医学领域（SNUH 韩语医学 + 普什图语医学推理），加上此前多轮持续出现的医学数据集（HealMed、GlobalMedQA、Multilingual-Medical-Corpus 等），医学正成为多语言 SFT 数据增长最快的垂直领域之一。这反映了 LLM 在医疗场景部署中对多语言能力的迫切需求。

### 2. 🌍 极低资源语言数据从"有无"走向"质量"
加纳 7 语言语音 Agent 数据（confana-sft）不仅覆盖 Twi、Ewe 等极低资源语言，还包含工具调用和质量标注——数据质量维度开始出现在极低资源语言数据中。这标志着极低资源语言数据建设正从单纯的"覆盖填补"向"高质量实用"演进。

### 3. 🗣️ 语音评估基准向语用层深入
YUE-PUB-Speech（Interspeech 2026）将评估从"能否听懂粤语"提升到"能否理解粤语语用含义"。这代表了多语言语音评估从 ASR 准确率向语义/语用理解的范式升级。

### 4. 🔧 Agent 工具调用数据多语言化加速
BFCL v3 Multilingual 和 confana-sft-multilingual 都包含工具调用评估/训练数据。随着 Agent 系统向全球部署，工具调用能力的多语言覆盖正成为刚需。
