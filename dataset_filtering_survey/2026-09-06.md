### 1. From Reweighting to Rewriting: Unlocking the Intervention Effects of Influential Samples in Training Data Attribution

| 字段 | 内容 |
|------|------|
| **作者** | Yuzhang Luo, Chenpeng Wang, Jianhui Chen, Liangming Pan |
| **年份** | 2026 |
| **来源** | arXiv:2609.02771 (cs.CL, cs.AI, cs.LG) |
| **链接** | https://arxiv.org/abs/2609.02771 |
| **提交日期** | 2026-09-02 |
| **分类** | 数据归因 / 数据质量干预 |

#### 方法摘要

训练数据归因（TDA）的目标是识别塑造模型行为的训练样本，但其**干预价值**取决于"选哪些样本"和"如何修改它们"两个维度。影响函数（Influence Functions, IF）在无穷小重新加权下估计行为变化，但传统基于权重的干预方法下，IF 选出的样本相比随机选择并无显著优势。

本文提出 **influence-guided response rewriting**：用 IF 识别干预目标后，将其 response 替换为行为一致或行为相反的监督信号（保持 instruction 不变），而非简单调整权重。在 4 个开源 LLM 上，以 **epistemic abstention**（认知弃权）为主要测试平台，证明 rewriting 产生**更强、更持久、可双向控制**的行为变化，而 reweighting 同一批样本的效果微弱且不一致。

#### 关键方法

- **Influence-guided response rewriting** — 利用影响函数定位关键样本，直接重写其 response 内容
- **Epistemic abstention testbed** — 以模型"知之为知之、不知为不知"的能力作为行为探针
- **Safety refusal intervention** — 将同样的 rewriting vs reweighting 对比扩展到安全拒绝行为
- **Bidirectional behavioral shift** — 证明 rewriting 可双向增强或抑制目标行为

#### 核心结论

影响函数选出的样本的**干预杠杆价值**远高于 reweighting 所能释放的——问题不在于" influential examples 没用"，而在于"reweighting 无法实现它们的干预潜力"。这要求在评估 TDA 方法时，区分**局部 reweighting 效应**和**更广泛的干预杠杆**。

#### 实用价值评估

| 维度 | 评分 | 说明 |
|------|------|------|
| 对多语言数据集构建的参考价值 | ⭐⭐⭐ | 中等。虽未直接涉及多语言场景，但"识别+重写"范式可迁移至多语言数据质量控制 |
| 方法创新性 | ⭐⭐⭐⭐ | 高。首次系统对比 rewriting vs reweighting 作为 TDA 的干预手段 |
| 工程可落地性 | ⭐⭐ | 低。需要计算影响函数（计算开销大），且 rewriting 需要 LLM 辅助生成 |
| 理论贡献 | ⭐⭐⭐⭐ | 高。揭示了 TDA 评估中"选择"与"干预"的解耦问题 |

## 📊 趋势洞察

### 1. 数据归因（TDA）成为持续深化的方向

本期论文进一步巩固了**训练数据归因**作为数据策划核心方向的地位。在历史报告中，我们已识别到：
- "Data Attribution in Large Language Models via Bidirectional Gradient Optimization"
- "Beyond Shapley: An Influence-Based Data Auditing Pipeline"
- "Measuring Task-Agnostic Training Data Influence Across Language Model Pretraining"
- "DataDignity: Training Data Attribution for Large Language Models"
- "Mechanistic Data Attribution" / "LoRIF" / "Concept Influence"

本文的贡献在于**从"识别"走向"干预"**——不再只是问"哪些数据影响了模型"，而是"如何利用这些发现来主动改变模型行为"。

### 2. "选择 vs 干预"的解耦是新方法论挑战

本文揭示了一个关键问题：**数据选择方法的价值 ≠ 基于该选择的干预方法的价值**。这意味着：
- 之前的 data selection 论文（如 coresets、influence-based selection）可能因使用了不当的干预方式而低估了选择方法本身的潜力
- 未来评估数据选择方法时，需要同时考虑"选得好"和"用得好"两个维度

### 4. 对多语言数据集构建的启示

- **间接但深远**：如果将 influence-guided rewriting 应用于多语言数据，可以识别哪些样本对特定语言的行为最关键，并针对性地重写/增强
- **实用路径**：在多语言 SFT 数据中，先用 IF 识别对目标语言能力影响最大的样本，然后对这些样本进行针对性改写（如翻译质量修正、文化适配调整），可能比全量数据过滤更高效
- **局限**：影响函数在大规模预训练中的计算开销仍是瓶颈，当前更适合 post-training 阶段的数据策划

## 💡 建议

### 值得深入研究的方向

1. **Intervention-aware TDA evaluation** — 本文提出的"rewriting 比 reweighting 更能释放 influential samples 价值"的结论，可能改变整个 TDA 评估范式。建议跟踪后续工作
2. **Rewriting 与数据合成的交叉** — 将 influence-guided rewriting 与合成数据生成（如 Autodata、Simula）结合，可能产生更强的数据增强方法
