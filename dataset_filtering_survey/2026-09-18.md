## 🆕 新增数据集资源

### 📌 评估基准（Evaluation Benchmarks）— 10 项

#### 1. MAPS (Fujitsu-FRE)
- **链接**: https://huggingface.co/datasets/Fujitsu-FRE/MAPS
- **语言覆盖**: 11 语言 (en, zh, ja, ko, de, fr, es, pt, it, ar, hi, ru)
- **描述**: 多语言 Agent 性能与安全基准。翻译 4 个主流 Agent 基准（GAIA、SWE-Bench、MATH、Agent Security Benchmark）至 11 种语言，含 805 个独特任务、9,660 个实例。首个标准化多语言 Agent 评估框架。
- **实用价值**: ⭐⭐⭐⭐⭐ — **极高**。直接可用于评估多语言 Agent 能力，覆盖主流语言。建议纳入多语言模型评估 pipeline。

#### 2. GaoYao
- **链接**: https://github.com/lunyiliu/GaoYao
- **语言覆盖**: 26 语言，51 个国家/地区
- **描述**: 综合多语言多文化能力基准，182.3K 样本。3 层文化框架（通用多语言、跨文化、单文化）+ 9 个认知子层。ACL 2026 长文。
- **实用价值**: ⭐⭐⭐⭐⭐ — **极高**。文化维度评估是差异化亮点，对多语言模型的「文化适配」评估具有开创意义。

#### 3. GlobeAudio (iNLP-Lab)
- **链接**: https://huggingface.co/datasets/iNLP-Lab/GlobeAudio
- **语言覆盖**: 6 语言 (en, zh, es, hi, ar, sw)
- **描述**: 多语言多文化音频语言模型评估基准。5,637 道多选题，由母语者基于自然音频构建，测试高阶听觉推理和文化理解。
- **实用价值**: ⭐⭐⭐ — 中等。音频模态+多文化的交叉评估是创新点，但对纯文本多语言 LLM 训练参考价值有限。适用于多模态多语言模型评估。

#### 4. Cross-lingualIFEval
- **链接**: https://huggingface.co/datasets/vojewale/Cross-lingualIFEval
- **语言覆盖**: 5 语言 (en, ar, fr, es, de)
- **描述**: 跨语言指令遵循评估数据集，测试 LLM 跨语言遵循复杂格式指令的能力（JSON、Markdown、字数限制、分隔符等）。
- **实用价值**: ⭐⭐⭐⭐ — 高。跨语言指令遵循是实际部署中的关键能力，对评估多语言 SFT 效果很有价值。

#### 5. MAST Benchmark (multilingual-queries-2026)
- **链接**: https://huggingface.co/datasets/mast-benchmark/multilingual-queries-2026
- **语言覆盖**: ar, bn, cy, de, en 等
- **描述**: 2026 年多语言 QA 基准查询集，用于评估问答和文本检索系统的跨语言能力。
- **实用价值**: ⭐⭐⭐ — 中等。覆盖威尔士语 (cy) 等少见于基准的语言，但整体规模有限。

#### 6. Cross-lingual Rule Following Eval
- **链接**: https://huggingface.co/datasets/crosslingual-rule-following/rule-following-eval
- **语言覆盖**: 5 语言 (en, ko, es, de, fr)
- **描述**: 跨语言规则遵循评估，含正则表达式和 LLM-judge 评估标准。
- **实用价值**: ⭐⭐⭐ — 中等。与 Cross-lingualIFEval 互补，侧重规则遵循而非格式遵循。

#### 7. Cross-lingual Clinical RAG Study

#### 10. Model Inference Responses (Cross-lingual)

## 📊 趋势洞察

### 1. 多语言评估基准的「文化转向」

本期最显著的趋势是评估基准从纯语言能力测试向**文化能力测试**延伸：
- **GaoYao** 明确引入 3 层文化框架（通用/跨文化/单文化）
- **Pluralis** 从「文化优先」视角构建安全评估
- **CultSportQA** 通过传统体育测试文化理解
- **GlobeAudio** 测试文化根植的音频理解

这标志着社区认知从「多语言 = 翻译」到「多语言 = 文化适配」的范式转移。

### 2. 安全对齐数据的低资源语言扩展

- **LSR Anchoring** 覆盖 Yoruba、Hausa、Igbo — 这些语言在安全对齐研究中几乎完全被忽视
- **Multilingual Safety Probe** 纳入泰卢固语和塞尔维亚语
- 反映安全研究从「主要语言」向「所有语言」的覆盖意识

### 3. Agent 评估的多语言化

- **MAPS** 是首个标准化多语言 Agent 评估框架
- **Nemotron-SFT-Agentic-v2** 反映 Agent SFT 数据的持续演进
- 多语言 Agent 能力正成为新的评估必选项

### 4. 数据模态与长度的分化

- **UltraData** 按上下文长度分段（8K-32K / 32K-200K）
- **GlobeAudio** 引入音频模态
- **Pluralis** 引入多模态（文本+图像）安全评估
- 反映多语言数据集从「纯文本+通用长度」向「多模态+长度分层」的精细化发展

### 5. 与历史报告的对比

## 💡 建议

### ✅ 值得深入研究的方向

1. **多语言 PII 检测** — `filtered-multilingual-pii`（945K 行）可直接用于训练多语言 PII 过滤器，是数据清洗 pipeline 的刚需
2. **跨文化评估框架** — GaoYao 和 Pluralis 的文化分层评估方法论值得借鉴
3. **多语言 FAQ 检索资源** — WebFAQ 2.0 的 1.98 亿 QA 对 + 108 语言覆盖是构建多语言检索系统的基石
4. **南亚语言经济语料** — BENI Global 10 填补了全球南方语言在经济领域的空白

### 🛠️ 建议纳入 pipeline 的资源

| 优先级 | 资源 | 理由 |
|--------|------|------|
| P0 | WebFAQ 2.0 | 108 语言、1.98 亿 QA 对、双语对齐、持续更新 |
| P0 | Filtered Multilingual PII | 945K 行、6 语言 PII 标注，直接可用于 PII 过滤训练 |
| P1 | MAPS | 11 语言 Agent 评估，直接可用于模型评估 |
| P1 | GaoYao | 26 语言文化评估，提供独特评估维度 |
| P1 | UltraData-SFT no-think 系列 | 中英双语 + 长度分层的 SFT 数据，实用训练策略 |
| P2 | Multilingual News Ukraine | Nature 发表的高质量多语言新闻语料 |
