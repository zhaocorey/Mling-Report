### 1. Dataset Distillation by Influence Matching (InfMatch)

- **链接**: https://arxiv.org/abs/2607.16859
- **作者**: Haoru Tan, Wang Wang, Sitong Wu, Xiuzhe Wu, Yangtian Sun, Chirui Chang, Shaofeng Zhang, Xiaojuan Qi
- **年份**: 2026 (CVPR 2026)
- **类别**: sampling / dataset distillation
- **方法摘要**: 从结果导向视角重新审视数据集蒸馏。提出 Influence Matching (InfMatch)，学习一个紧凑合成数据集使其对收敛参数的影响匹配完整数据集。引入完全可微的样本级 influence 估计器，线性时间复杂度，无需逆 Hessian 乘积。在 Tiny-ImageNet (IPC=10) 上超过 NCFM +4.7%，并扩展到 Flickr30K 视觉语言蒸馏。
- **关键方法**: influence-based distillation, differentiable sample-level influence estimator, first-order Taylor approximation, outcome alignment
- **实用价值**: ⭐⭐⭐⭐⭐ — 消除了传统蒸馏方法的计算瓶颈（逆 Hessian），线性时间可扩展。对大规模数据压缩有直接应用价值。CVPR 2026 主会。

### 2. Judging Quality Across Languages (JQL)

- **链接**: https://arxiv.org/abs/2505.22232
- **作者**: Mehdi Ali, Manuel Brack, Max Lübberling, Elias Wendt 等 18 位作者
- **年份**: 2025
- **类别**: quality / multilingual filtering
- **方法摘要**: 系统性的多语言大规模数据筛选方法。将 LLM 的质量判断蒸馏为高效的跨语言过滤模型。解决现有 SOTA 数据集依赖启发式过滤方法、跨语言迁移性有限的问题。
- **关键方法**: LLM-distilled quality filtering, cross-lingual quality judgment transfer, multilingual data curation at scale
- **实用价值**: ⭐⭐⭐⭐ — 与 MuRating（已在基线）互补：MuRating 聚焦质量评估，JQL 聚焦过滤效率。对多语言预训练数据构建有直接参考价值。

### 1. DeMix Corpora & Code

- **链接**: https://github.com/Lucius-lsr/DeMix
- **来源论文**: DeMix (ICML 2026)
- **功能**: 22T-token 数据集 + model-merging-based data mixture 优化代码。包含组件模型训练脚本和基于加权合并的代理评估。
- **与现有工具对比**: 补充了 DoReMi 等动态混合方法，提供解耦搜索-训练范式的实际实现。22T tokens 是已知最大规模的比例已知预训练语料之一。
- **实用价值**: ⭐⭐⭐⭐⭐ — 22T tokens 开放语料本身就是重要资源，加上合并搜索代码，对 data mixing 研究极有价值

### 2. InfMatch

- **链接**: https://github.com/hrtan/infmatch
- **来源论文**: Dataset Distillation by Influence Matching (CVPR 2026)
- **功能**: 完全可微的线性时间 influence 估计器，用于学习紧凑合成数据集。
- **与现有工具对比**: 不同于 gradient matching / trajectory matching 等现有蒸馏方法，InfMatch 基于 outcome-based influence，精度更高。
- **实用价值**: ⭐⭐⭐⭐ — 新发布代码（CVPR 2026），成熟度待观察，但方法创新性强

### 3. Microsoft Data-Efficacy (STR/SAW)

## 📊 趋势洞察

### 一、数据集蒸馏进入 influence-based 时代
InfMatch (CVPR 2026) 代表了数据集蒸馏的新方向：从梯度匹配/轨迹匹配转向基于 influence 的结果导向方法。线性时间复杂度 + 无需逆 Hessian 使其可扩展到大规模场景。结合 Open Distillation Datasets 的出现，蒸馏工具生态正在快速成熟。

### 二、多语言数据质量形成方法论闭环
JQL + MuRating 两篇工作形成互补：
- **MuRating**: 英语质量信号 → 跨语言迁移 → 多语言评估器
- **JQL**: LLM 质量判断 → 蒸馏 → 高效跨语言过滤器

二者共同指向：**多语言数据质量评估正在从启发式规则走向 LLM 蒸馏模型**。

### 三、数据组织（ordering）开始工具化
Microsoft Data-Efficacy 是首个专门优化数据排序的工具，标志着 data curation 的三个维度都已有工具支持：
- **选择什么** (selection) → 各种 quality filter 工具
- **怎么混合** (mixing) → DeMix, DoReMi
- **什么顺序** (ordering) → Data-Efficacy ← **新增**

### 四、GPU 加速 curation 成为标配
Spheron 的指南给出了明确的吞吐对比：GPU 精确去重比 CPU 快 9 倍，MinHash LSH 快 13 倍。这意味着对于万亿 token 级别的语料，GPU curation 不再是可选项而是必须。
