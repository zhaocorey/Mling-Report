### 1. Advancement or Acceleration? How Data Curation Improves LLM Training

| 字段 | 内容 |
|------|------|
| **作者** | Jiaxing Wang 等 |
| **年份** | 2026 |
| **链接** | [arXiv:2610.36983](https://arxiv.org/abs/2610.36983) |
| **类别** | Quality / 理论分析 |
| **提交日期** | 2026-10-27 |

**方法摘要：** 本文形式化了数据策展中一个基础但长期模糊的问题：策展到底扩展了模型能学到的上限（advancement），还是仅仅加速了到达同一解的过程（acceleration）？作者通过解析推导和真实 LLM 实验证明，advancement 要求存在可修正的 train-target gap。当基线训练与目标分布一致时，任何策展策略都无法提升终点性能（但仍可能加速训练）。论文提出 Δ-test——一个在昂贵策展前即可计算的、基于未策展基线训练/目标损失差异的可观测量，用于预测策展是否能带来持续收益。

**关键方法：**
- Advancement vs Acceleration 的形式化区分
- Δ-test：基于 train-target loss discrepancy 的策展收益预测器
- Gap-centric 视角统一 data mixture 和 data selection

**实用价值评估：** ⭐⭐⭐⭐（高）
- 对多语言数据集构建有重要指导意义：在多语言场景中，不同语言域的 train-target gap 差异巨大，Δ-test 可用于判断哪些语言域值得投入策展资源
- 理论优雅，结论可直接指导工程实践

### 2. Adapting English Quality Classifiers for Multilingual LLM Pretraining Data Selection

| 字段 | 内容 |
|------|------|
| **作者** | Vinko Sabolčec 等 |
| **年份** | 2026 |
| **链接** | [arXiv:2610.11585](https://arxiv.org/abs/2610.11585) |
| **类别** | Filtering / 多语言 |
| **提交日期** | 2026-10-08 |

**方法摘要：** 本文提出将英语质量分类器适配到 100+ 种语言的多语言变体。核心方法是在 Transformer encoder-only 模型的嵌入层上训练一个小型 MLP，以多语言文本为输入、英语分类器对机器翻译文本的评分为标签。1B/3B/8B 规模实验表明，该方法在下游 LLM 基准上保持了现有多语言模型过滤基线的性能，同时不损害区域和文化知识基准。分类器甚至能对训练集中未包含的语言学到评分标准。

**关键方法：**
- English → Multilingual 质量分类器迁移
- 基于机器翻译评分的弱监督训练
- 100+ 语言覆盖（包括低资源语言）

**实用价值评估：** ⭐⭐⭐⭐⭐（极高）
- **直接服务于多语言数据集构建**：解决了多语言质量过滤的核心痛点——缺乏非英语标注数据
- 方法轻量（仅需小 MLP），可快速部署到新语言
- 与本项目高度相关，建议纳入 pipeline 评估

### 3. Register-based Data Selection for Multilingual LLMs

| 字段 | 内容 |
|------|------|
| **作者** | Tomasz Galica, Amanda Myntti, Erik Henriksson 等 |
| **年份** | 2026 |
| **链接** | [ACL Anthology: 2026.findings-emnlp.4](https://aclanthology.org/2026.findings-emnlp.4/) |
| **类别** | Filtering / 多语言 |
| **发表** | EMNLP 2026 Findings |

**方法摘要：** 本文提出基于 Internet registers（网络文体/体裁）和 Web Document Score (WDS) 的多语言数据选择策略。研究覆盖 15 种欧洲语言（使用 HPLT 3.0 数据集），为每种语言训练 4 个小型生成式 LM，分析不同 registers 和 WDS 对模型训练的影响。结果表明，register-based selection 与 WDS 的组合方法在语言、知识和推理任务上均有提升，且可跨语言泛化。

**关键方法：**
- Internet register（体裁）驱动的数据选择
- Web Document Score (WDS) 与 register 组合过滤
- 15 种欧洲语言的实证验证

**实用价值评估：** ⭐⭐⭐⭐（高）
- 提供了超越"质量分数"的结构化数据选择视角
- 对欧洲语言覆盖较好，但亚洲语言覆盖有限
- Register 分类可作为多语言 pipeline 的辅助信号

### 4. VidUEU-Agent: A Data-Curation Agent for Multimodal Understanding, Editing, and Unified Tasks

| 字段 | 内容 |
|------|------|
| **作者** | Luca 等 |
| **年份** | 2026 |
| **链接** | [arXiv:2611.04418](https://arxiv.org/abs/2611.04418) |
| **类别** | Construction / 多模态 |
| **发表** | NeurIPS 2026 Poster |

**方法摘要：** VidUEU-Agent 是一个自动化视频指令数据合成 pipeline。它通过全局感知过滤低质量镜头，从关键帧和多模态信号构建元数据，然后路由到不同任务（理解、编辑、统一任务）生成指令样本。pipeline 支持自主迭代优化，最终产出 100K 规模的指令数据集。

**关键方法：**
- 四阶段视频数据策展 pipeline（感知→挖掘→构建→路由）
- 自主迭代优化（Auto-Iteration）
- 多模态指令数据合成

**实用价值评估：** ⭐⭐（一般）
- 主要面向视频-多模态场景，与文本为主的多语言数据集构建关联较弱
- Agentic 数据策展的思路值得借鉴，但直接应用价值有限

### 1. SemHash — 快速多模态语义去重与过滤

| 字段 | 内容 |
|------|------|
| **名称** | SemHash |
| **链接** | [github.com/MinishLab/semhash](https://github.com/MinishLab/semhash) |
| **Stars** | ⭐ 979 |
| **Forks** | 57 |
| **类别** | Dedup / 去重 |
| **最后更新** | 2026-11-08 |

**功能描述：**
SemHash 是一个轻量级、多模态的语义去重库，支持：
- **自去重**（self_dedup）：清理训练集中的重复/近似重复样本
- **跨数据集去重**：将测试集与训练集去重
- **异常值过滤**：识别并移除离群样本
- **代表性样本选择**：找出数据集中最具代表性的样本

文本开箱即用（基于 Model2Vec 嵌入），图片/音频等模态支持自定义编码器。**支持多语言**（提供 `minishlab/potion-multilingual-128M` 模型）。

| 多模态 | ✅ | ❌ 文本 | ❌ 文本 | ❌ 文本 |
| 多语言 | ✅ 专用模型 | 部分 | ✅ | 部分 |
| 易用性 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐ | ⭐⭐ |
| 规模 | 中等 | 大规模 | 超大规模 | 理论验证 |

**实用价值评估：** ⭐⭐⭐⭐⭐（极高）
- 轻量、易用、多模态、多语言，非常适合中小规模多语言数据集的快速去重
- `pip install semhash` 即可使用，集成 HuggingFace datasets
- 建议纳入 pipeline 作为去重阶段的候选工具

## 💡 建议

### 🟢 值得深入研究的方向

1. **英文→多语言质量分类器迁移** — 直接验证 arXiv:2610.11585 的方法在我们的多语言数据集上的效果。优先级最高，因为：
   - 解决了低资源语言缺乏质量标注的核心问题
   - 方法轻量（小 MLP + 预训练嵌入）
   - 与现有 pipeline 无缝衔接

2. **Register-based 多语言过滤** — 探索将体裁分类集成到我们的过滤 pipeline 中，特别是对亚洲语言的适用性验证

3. **Δ-test 在多语言场景的验证** — 对不同语言域计算 Δ 值，验证其是否能预测策展收益
