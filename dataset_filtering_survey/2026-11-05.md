## 🆕 新增论文（7 篇）

### 1. Advancement or Acceleration? How Data Curation Improves LLM Training

- **来源**：arXiv:2610.36983（2026-10）
- **分类**：`curation-theory` / `quality-assessment`
- **核心贡献**：
  - 形式化定义了数据策展中的"进步"（advancement，提升可达性能上限）vs"加速"（acceleration，更快达到相同性能）
  - 提出 **Delta-test** 作为可观测的策展收益预测器
  - 指出进步需要可修正的 train-target gap
- **实用价值**：⭐⭐⭐⭐  
  对多语言数据集构建有**方法论指导意义**——在决定投入资源做数据清洗前，可用 Delta-test 评估该操作是带来真正的性能上限提升，还是仅仅加速收敛。避免在已"足够好"的数据上做无效策展。

---

### 2. AQL-Lite: Enabling Efficient Knowledge Acquisition for Arabic LLMs

- **来源**：arXiv:2610.30344（2026-10）
- **分类**：`filtering` / `quality` / `multilingual`
- **核心贡献**：
  - 提出质量优先的策展流水线：结构清洗 → 启发式+模型过滤 → MSA 选择 → 去重
  - 配合部分参数 CPT（Continual Pretraining）方案
  - 在 **40B MSA token** 规模上验证，以 52% 训练时间恢复 94% 的全参数 CPT 收益
- **实用价值**：⭐⭐⭐⭐⭐  
  **对多语言数据集构建参考价值极高**。阿拉伯语是典型的低资源+高形态复杂度语言，其质量过滤流水线可直接迁移至其他形态丰富语言（如中文方言、藏语等）。部分参数 CPT 策略降低了多语言适配成本。

---

### 3. TiKMiX: Efficient Semi-Dynamic Data Mixture via Data Influence

- **来源**：ACL 2026 主会
- **分类**：`mixing` / `pretraining`
- **核心贡献**：
  - 基于**数据影响力排序不变性**（influence ranking invariance）观察，提出半动态混合策略
  - 在静态混合（次优但高效）和全动态混合（最优但昂贵）之间找到折中点
  - 无需每轮重新评估数据价值，降低计算开销
- **实用价值**：⭐⭐⭐⭐⭐  
  ACL 主会工作，影响力排序不变性是一个**强实用洞察**——对大规模多语言预训练意味着：可以定期（而非持续）更新混合比例，大幅降低工程复杂度。

---

### 4. DaMo: Data Mixing Optimizer in Fine-tuning Multimodal LLMs

- **来源**：ACL 2026 Findings
- **分类**：`mixing` / `multimodal` / `fine-tuning`
- **核心贡献**：
  - 面向多模态 LLM 微调的数据混合优化器
  - 针对手机智能体（mobile phone agents）场景的多任务 SFT 数据配比优化
  - 自动化搜索最优训练数据组合
- **实用价值**：⭐⭐⭐  
  虽然场景偏向多模态/智能体，但其**混合优化框架设计思路可迁移**——在多语言 SFT 阶段，不同语言/任务的数据配比同样关键。方法论参考价值大于直接复用价值。

---

### 5. Optimizing Training Data Diversity with DataSpinner

- **来源**：IEEE（11661205）
- **分类**：`sampling` / `diversity` / `LLM-agent`
- **核心贡献**：
  - LLM 驱动的策展 Agent，将数据集多样性优化建模为**序列决策问题**
  - 对抗分布坍缩（distributional collapse）——训练语料收敛到狭窄低多样性子集
  - Agent 逐步决定保留/丢弃/增强哪些样本以提升多样性
- **实用价值**：⭐⭐⭐⭐  
  分布坍缩是多语言数据集构建中的**真实痛点**——小语种数据容易被过滤算法系统性淘汰。DataSpinner 的 Agent 范式提供了一种动态补偿策略，值得在多语言场景中评估。

---

### 6. Scalable Entity-Centric Data Filtration for LLM Pretraining

- **来源**：IEEE（11723055）
- **分类**：`filtering` / `deduplication`
- **核心贡献**：
  - 以**实体**作为紧凑语义锚点，识别并移除预训练语料中的冗余/低信息密度内容
  - 可扩展到大规模语料
  - 超越传统 n-gram/MinHash 去重，进入语义级去冗余
- **实用价值**：⭐⭐⭐⭐  
  对多语言数据集构建有直接价值——**跨语言实体**可作为统一锚点，帮助识别翻译文本与原文的冗余、同一事件的多语言重复报道等。在构建平行语料或多语言知识库时尤其有用。

---

### 7. DADFS: Dynamic Adaptive Data Filtering and Sampling

- **来源**：IEEE（10984505，2025-05）
- **分类**：`filtering` / `sampling` / `fine-tuning`
- **核心贡献**：
  - 三合一框架：动态自适应过滤 + 自适应采样 + 按比例加权数据混合
  - 集成 LoRA/PEFT 框架
  - 在微调阶段根据模型学习状态动态调整数据策略
- **实用价值**：⭐⭐⭐  
  综合性框架，但论文发表时间较早（2025-05），部分方法可能已被后续工作超越。作为**基线参考**有价值，其"过滤+采样+混合"三位一体的设计思路值得借鉴。

## 📊 趋势洞察

### 1. 数据混合策略的"实用化"转向
TiKMiX（半动态）、DaMo（自动优化器）、DataSpinner（Agent 驱动）分别从不同角度解决同一问题：**如何以可控成本找到最优数据配比**。TiKMiX 的"排序不变性"洞察最值得关注——它暗示我们不需要持续重新评估数据价值，降低了工程门槛。

### 2. 从"通用过滤"到"场景感知过滤"
AQL-Lite（阿拉伯语特化）、Entity-Centric（实体锚定）、DADFS（微调阶段自适应）都在强调：**过滤策略必须适配目标场景**。"一套过滤规则打天下"的时代正在结束。

### 3. LLM Agent 作为数据策展者
DataSpinner 将数据多样性优化建模为序列决策问题，用 LLM Agent 做策展决策。这代表了一个新范式：**让模型自己判断什么数据该留、什么该丢**，而非依赖人工设计的规则。

### 4. 全链路框架的崛起
Marin 的出现标志着社区开始需要**标准化的数据研究基础设施**，而非零散的一次性脚本。这对多语言数据集构建是好消息——工程经验可以被沉淀和复用。

### 5. 理论指导实践
"Advancement or Acceleration" 提供了形式化框架来评估策展工作的实际收益。这对资源分配决策至关重要：**避免在已经"足够好"的数据上浪费算力**。
