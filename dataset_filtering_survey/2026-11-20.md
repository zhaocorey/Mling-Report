## 🆕 新增论文

### 1. Ambient LLMs: Data-Efficient Supervised Fine-tuning via Temperature Matching

| 属性 | 内容 |
|------|------|
| **作者** | Giannis Daras, Marios Papachristou, Adam Klivans, Antonio Torralba, Constantinos Daskalakis |
| **年份** | 2026 |
| **链接** | https://arxiv.org/abs/2611.23229 |
| **类别** | 🎯 Sampling / SFT |
| **相关性** | ⭐⭐⭐⭐ 高 |

**方法摘要：** 针对 SFT 数据量远小于预训练数据时导致的过拟合和灾难性遗忘问题，提出"Ambient LLMs"概念。核心方法是通过温度匹配（temperature matching）技术，使微调后的模型分布保持预训练模型的分布尾部特征。这使得在极小的后训练数据集上也能实现高效的监督微调，同时保留模型的通用能力。

**关键方法：** Temperature Matching, Distribution Preservation, Data-Efficient SFT

**实用价值：** 对多语言数据集构建有直接参考价值。当目标语言的标注数据稀缺时，如何避免微调灾难性遗忘是核心挑战。温度匹配方法提供了一种理论上优雅的解决方案，值得在多语言 CPT/SFT 场景中评估。

### 2. Data Attribution Should Steer Pretraining

| 属性 | 内容 |
|------|------|
| **作者** | Glenn Matlin, Chandreyi Chakraborty, Mohammed Rehan Parwani 等 |
| **年份** | 2026 |
| **链接** | https://arxiv.org/abs/2611.19698 |
| **类别** | 📌 Data Curation / Attribution |
| **相关性** | ⭐⭐⭐⭐ 高 |

**方法摘要：** 提出基于影响函数（influence function）的动态数据策展框架，将 data attribution 从"事后分析"提升为"实时 steering"。核心思想是：一个文档的价值取决于模型**已经知道什么**——随着训练进行，数据的影响分布会动态变化。该方法在预训练过程中持续评估数据影响并调整数据调度策略。

**关键方法：** Influence-driven Data Curation, Dynamic Data Scheduling, Pretraining Steering

**实用价值：** 对大规模多语言预训练有重要参考意义。传统静态数据混合（如 fixed mixing ratios）可能不是最优的——随着模型对不同语言/领域的学习进度不同，动态调整数据配比可能显著提升效率。这与历史报告中多次出现的"在线重加权"趋势一致。

### 3. Data-Efficient LLM Safety Alignment Guided by Interpretable Features

| 属性 | 内容 |
|------|------|
| **作者** | （未列出） |
| **年份** | 2026 |
| **链接** | https://arxiv.org/abs/2611.16183 |
| **类别** | 🔍 Filtering / Safety |
| **相关性** | ⭐⭐⭐⭐⭐ 极高 |

**方法摘要：** 提出 **"Less is Safer"（LIS）** 方法：利用稀疏自编码器（SAE）的可解释特征来指导安全对齐数据的筛选与对抗性合成。仅用 **2.4K 样本**的安全数据集，在安全性和过度拒绝（over-refusal）基准上超越了 TRIDENT-Core（26K）和 WildJailbreak（262K）等大规模数据集。证明了 SAE 可解释特征能有效指导数据选择，实现"少而精"的安全对齐。

**关键方法：** SAE-interpretable Features, Feature-guided Selection, Adversarial Synthesis, Compact Safety Dataset

**实用价值：** **极高。** 这篇论文的核心洞见对多语言安全对齐有直接指导意义：
1. SAE 特征可以跨语言定位安全风险概念，为多语言安全过滤提供新信号
2. "少而精"的策略在多语言场景中尤其重要——为每种语言构建大规模安全数据集成本极高
3. 与历史报告中的 "Follow the Features" (SAE-guided instruction tuning) 形成方法论闭环

### 4. Rethinking Data Selection: The Importance of Coverage over Difficulty in LLM Fine-Tuning

| 属性 | 内容 |
|------|------|
| **作者** | （未列出） |
| **年份** | 2026 |
| **链接** | https://arxiv.org/abs/2611.07323 |
| **类别** | 🎯 Sampling / Selection Strategy |
| **相关性** | ⭐⭐⭐⭐ 高 |

**方法摘要：** 挑战了"更难的样本更有信息量"这一广泛假设。研究发现，基于难度的选择方法在 LLM 微调中往往无法超越随机选择，因为随机选择具有更好的输入空间覆盖率。提出基于聚类的选择方法，优先考虑代表性（representativeness），在 Tülu 3 的多样化混合数据上超越了所有现有方法。

**关键方法：** Clustering-based Selection, Coverage-first Strategy, Representativeness over Difficulty

**实用价值：** 对多语言数据选择策略有重要启示。在多语言场景中，如果过度依赖"难度"信号（如 perplexity），可能会系统性地忽视某些语言或领域中"简单但重要"的数据。覆盖率优先的策略更适合语言多样性场景。

> ⚠️ **注意：** 此论文与此前已报告的 *"Rethinking Data Selection: The Importance of Coverage over Difficulty in Generative Fine-Tuning"*（arXiv: 2504.01542）标题高度相似，核心发现一致。可能是同一团队的后续工作或会议版本，需进一步核实。

### 5. LECAT: Measuring LLM Category Learning from Pretraining Data

| 属性 | 内容 |
|------|------|
| **作者** | Jimin Mun, Maarten Sap, Yanai Elazar |
| **年份** | 2026 |
| **链接** | https://arxiv.org/abs/2611.18419 |
| **类别** | 📊 Quality / Analysis |
| **相关性** | ⭐⭐⭐ 中 |

**方法摘要：** 提出 LeCat 框架，分析 LLM 如何从预训练数据中获取类别知识。核心研究问题是组合性类别理解——例如模型学到"飞机是快的"后，是否能推广到"红色飞机"但不推广到"坏掉的飞机"。通过这种细粒度的知识追踪，揭示预训练数据中哪些内容被有效学习、哪些被忽略。

**关键方法：** Category Knowledge Tracking, Compositional Understanding Analysis, Pretraining Data Effectiveness Measurement

**实用价值：** 偏分析性质，但对理解多语言知识获取有间接参考价值。不同语言的语料可能传递不同类型的知识——LeCat 的方法论可以帮助评估多语言预训练后的知识分布。

### 6. Hidden Cartographer: Hidden State Guided Data Selection for Dual Budgeted Instruction Tuning

| 属性 | 内容 |
|------|------|
| **作者** | Zixuan Qin, Qi Qin, Erbo Li, Ting Wei, Yifan Sun, Zhaoxin Fan |
| **年份** | 2026 |
| **链接** | https://arxiv.org/abs/2610.23105 |
| **类别** | 🎯 Sampling / Instruction Tuning |
| **相关性** | ⭐⭐⭐ 中 |

**方法摘要：** 在双重预算约束（标注成本 + 训练算力）下，利用模型内部隐状态（hidden states）指导指令微调数据的选择。核心思想是：模型的内部表征已经编码了关于"哪些数据最有信息量"的信号，无需额外的代理模型或梯度计算即可实现高效数据选择。

**关键方法：** Hidden State-guided Selection, Dual Budget Optimization, Instruction Data Selection

**实用价值：** 对多语言指令微调有参考价值。多语言指令数据的标注成本极高（需要母语者），在有限预算下如何选择最有价值的数据是实际需求。利用模型自身隐状态作为选择信号，计算开销远低于梯度方法。

## 📊 趋势洞察

### 本次发现的关键趋势

1. **模型内部信号 > 外部启发式**
   - Hidden states（Hidden Cartographer）、SAE features（LIS）、influence functions（Data Attribution Should Steer Pretraining）——模型自身的内部状态正在取代 perplexity、难度分数等外部指标，成为数据选择的核心信号源
   - 这与历史报告中 "Follow the Features"、"Neuron-Guided Fine-Tuning" 等方向一脉相承

2. **"少而精"范式的持续验证**
   - 2.4K 安全数据 > 262K 大规模数据集（LIS 论文）
   - 温度匹配实现数据高效 SFT（Ambient LLMs）
   - 进一步强化了"数据质量远比数量重要"的共识

3. **覆盖率作为新的选择原则**
   - Coverage > Difficulty 获得独立验证
   - 聚类方法确保输入空间的均匀覆盖
   - 对多语言场景有天然优势

### 与之前调研的对比分析

| 维度 | 历史趋势（前 19 期报告） | 本期新增信号 |
|------|--------------------------|-------------|
| **选择信号** | 梯度/影响力为主流 | 隐状态、SAE 特征加入 |
| **安全对齐** | 数据量驱动的防御策略 | "少而精"的 SAE 引导策略 |
| **Data Attribution** | 事后分析为主 | 实时 steering 预训练 |
| **覆盖 vs 难度** | 已有 Coverage > Difficulty 论文 | 独立复现+聚类方法验证 |
| **工具生态** | 成熟工具主导（Data-Juicer, NeMo） | 小型实验性仓库涌现，尚无突破 |

### 对多语言数据集构建的启示

1. **SAE 特征引导的跨语言安全过滤**：LIS 论文的方法可以推广到多语言场景——用 SAE 在多语言数据上识别安全相关的可解释特征，实现高效的安全数据筛选
2. **动态数据调度适配多语言学习进度**：Data Attribution Should Steer Pretraining 的方法可用于多语言预训练中——不同语言的学习曲线不同，动态调整数据配比可能优于固定比例
3. **覆盖率优先策略天然适合语言多样性**：在多语言数据选择中，确保各语言/领域的均匀覆盖比追求"高难度"样本更重要
