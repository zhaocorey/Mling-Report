### 1. Beyond Shapley: An Influence-Based Data Auditing Pipeline for LLM Alignment and Evaluation

- **作者**: Unknown
- **日期**: 2026-07-24
- **链接**: [arXiv 2607.22766](https://arxiv.org/abs/2607.22766)
- **类别**: quality/filtering
- **方法摘要**: 提出可扩展的无需重训练的数据审计 pipeline，近似 Shapley 值进行数据估值。将语义 k-NN 邻域映射为有向图，通过零样本/单样本条件对数似然变化评估数据效用。在 HelpSteer2 上实现 99.1% 的人工审计搜索空间缩减，并识别出 HH-RLHF 中隐藏的安全/事实偏好反转。
- **关键方法**: Influence-based data valuation, semantic k-NN graphs, zero-shot log-likelihood shifts
- **实用价值**: 🟢 **高** — 直接适用于对齐数据集质量审计，无需重训练即可评估数据影响力，对多语言对齐数据筛选有重要参考价值。

### 2. PPL-Factory: Task-Aware and Budget-Aware Data Selection from Language Modeling to Reasoning

- **作者**: Hang Zhang, Warren J. Gross
- **日期**: 2026-07-20
- **链接**: [arXiv 2607.18199](https://arxiv.org/abs/2607.18199)
- **类别**: selection
- **方法摘要**: 提出可解释的数据选择框架，结合任务感知困惑度评分与预算感知选择标准。仅使用 1% 训练数据即在 GSM8K 上超越 SOTA 数据选择方法；使用 10% 数据时，在 GSM8K 和 MATH 上分别超出全数据微调准确率 0.9 和 4.8 个百分点。
- **关键方法**: Task-aware perplexity scoring, budget-aware selection criteria
- **实用价值**: 🟢 **高** — 极低数据量即可达到优秀效果，对多语言 SFT 数据的高效选择有直接参考意义。

### 3. A Systematic Evaluation of Trajectory Data Curation for LoRA Fine-Tuning of Code Agents

- **作者**: Yunze Han
- **日期**: 2026-07-19 | ICIC 2026 (oral)
- **链接**: [arXiv 2607.17205](https://arxiv.org/abs/2607.17205)
- **类别**: filtering/quality
- **方法摘要**: 系统性实证研究轨迹数据过滤对 LoRA 微调的影响。提出双轴质量评分框架（Efficiency 和 Style），通过 16 组受控实验在 SWE-trajectory 数据集（67K 轨迹）上评估。揭示了规模依赖的质量-数量权衡关系，并识别出 error-retry rate 为主导的质量子维度。
- **关键方法**: Two-axis quality scoring (Efficiency + Style), controlled ablation experiments
- **实用价值**: 🟡 **中高** — 聚焦代码 agent 轨迹，但双轴评分框架可迁移至多语言 agent 数据质量评估。

### 4. BLADE: Scalable Bi-level Adaptive Data Selection for LLM Training

- **作者**: Unknown
- **日期**: 2026-06-26
- **链接**: [arXiv 2606.18650](https://arxiv.org/abs/2606.18650)
- **类别**: selection
- **方法摘要**: 提出无 Hessian 的双级自适应数据选择方法。外层优化数据选择权重，内层训练模型参数，通过一阶梯度近似避免 Hessian 计算。提供理论收敛保证，在大规模 LLM 训练中实现高效数据选择。
- **关键方法**: Bi-level optimization, Hessian-free gradient approximation, convergence guarantees
- **实用价值**: 🟢 **高** — 可扩展到大规模训练场景，理论保证使其适用于需要严格数据选择的多语言预训练。

### 5. The Long-Term Effects of Data Selection in LLM Fine-Tuning

- **作者**: Unknown
- **日期**: 2026-05-31
- **链接**: [arXiv 2605.30537](https://arxiv.org/abs/2605.30537)
- **类别**: selection
- **方法摘要**: 从长期视角研究数据选择的"近视效应"。发现当前最优的数据选择策略在长期微调中可能表现不佳，提出 LHAS（Long-term Horizon Aware Selection）框架，在选择时考虑长期学习动态而非仅当前损失降低。
- **关键方法**: Long-term horizon analysis, myopic effect identification, LHAS framework
- **实用价值**: 🟢 **高** — 揭示了数据选择中容易被忽视的长期效应，对多语言持续学习和课程学习策略有重要启示。

### 6. Data Quality over Capacity: Internalizing Documents into LoRA Adapters for Closed-Book QA

- **作者**: Unknown
- **日期**: 2026-07-22
- **链接**: [arXiv 2607.21861](https://arxiv.org/abs/2607.21861)
- **类别**: quality/filtering
- **方法摘要**: 研究如何通过数据质量提升而非数据量提升来优化 closed-book QA。通过单次数据 curation 将准确率从 57.7% 提升到 85.7%，展示了高质量数据对 LoRA 微调的关键作用。提出文档内化策略，将外部知识有效编码进适配器参数。
- **关键方法**: Single-pass data curation, document internalization, quality-first approach
- **实用价值**: 🟢 **高** — 强有力的实证证据支持质量优先策略，对多语言 QA 数据集的构建和筛选有直接指导意义。

## 📊 趋势洞察

### 本轮关键趋势

1. **数据选择从单维度走向多维度统一**：PPL-Factory（任务+预算感知）、Unified Data Selection（质量+多样性+难度）、DataChef（RL自动配方）展示了数据选择正在从单一指标优化转向多目标统一框架。

2. **长期效应和训练动态被重视**：The Long-Term Effects 揭示了数据选择的"近视效应"，EVODATA 将训练动态作为 curation 信号——数据选择不再只看即时 loss 下降，而是关注长期学习轨迹。

3. **去重技术向语义级别演进**：SemHash-LLM 将语义嵌入引入哈希去重，DataWarden 集成本地 LLM 做智能去重——传统 MinHash/SimHash 的时代正在被语义感知方法取代。

4. **数据质量 > 数据量的实证证据持续增强**：Data Quality over Capacity（57.7% → 85.7%）、PPL-Factory（1% 数据超 SOTA）等工作不断强化质量优先的实证基础。

5. **基准和评估框架出现**：DataPrep-Bench 标志着数据准备领域开始有系统化的评估标准，这是领域成熟化的信号。

### 对多语言数据集构建的启示

- **RegMix-D 和 DataChef** 对多语言预训练混合比例调优有直接价值——多语言场景中各语言的最优混合比例是关键问题
- **SemHash-LLM 的多粒度语义去重**对处理多语言 web 语料特别有价值，不同语言的文档结构和长度差异大，多粒度方法更灵活
- **Beyond Shapley 的审计 pipeline** 可用于评估多语言对齐数据中各语言/文化的数据贡献，发现潜在偏见
