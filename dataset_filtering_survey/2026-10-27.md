### 1. "High-Quality" Data for Early-Stage Instruction Tuning: An Empirical Study of Data Quality Metrics

| 字段 | 值 |
|------|------|
| 作者 | Sofia Serrano et al. |
| 年份 | 2026 |
| 链接 | https://arxiv.org/abs/2610.33969 |
| 类别 | Quality — 数据质量度量 |
| 实用价值 | ⭐⭐⭐⭐ (高) |

**方法摘要**：本文实证研究了 instruction tuning 中"数据质量"作为可操作性属性的定义。评估了多个 example-level 指标（response ratio 等）作为训练效用预测因子的有效性。发现在固定微调预算下，answer-dense supervision（response ratio）是比常用代理更强的训练效用预测因子。将指令-回复样本按分数排序后划分为 low/middle/high 三个分桶，通过验证困惑度和 LLM-as-judge 分数进行比较。

**关键方法**：
- Example-level quality metrics（response ratio 为核心指标）
- 分桶对比实验（low/mid/high quality bins）
- 验证指标：perplexity + LLM-as-judge

**实用价值评估**：对多语言 instruction tuning 数据的质量筛选具有直接参考价值。Response ratio 作为简单、无需额外模型的质量信号，可低成本集成到现有 pipeline 中。尤其适用于多语言 SFT 数据的初步质量分层。

### 2. MetaCurate: Evolving Curation Filters for High-Quality Agentic Coding Data

| 字段 | 值 |
|------|------|
| 作者 | （未标注） |
| 年份 | 2026 |
| 链接 | https://arxiv.org/abs/2610.23134 |
| 类别 | Filtering — 自动化数据筛选 |
| 实用价值 | ⭐⭐⭐ (中高) |

**方法摘要**：提出一种基于 pairwise LLM 判断的 trajectory curation filter 演化方法。采用 diagnostics-driven 策略：proposer 利用诊断分歧信号迭代优化 curation filter 的筛选标准。专门针对 agentic coding 任务的 trajectory 数据质量筛选问题，通过演化机制自动发现更优的筛选规则。

**关键方法**：
- Pairwise LLM judgment 驱动的 filter evolution
- Diagnostics-driven filter refinement（分歧信号反馈）
- 面向 agent trajectory 数据

**实用价值评估**：虽然针对 coding agent 场景，但"演化式 curation filter"的方法论可迁移到多语言数据筛选。其 diagnostics-driven 的反馈循环思路对构建自适应筛选 pipeline 有启发意义。目前实用价值中等，需观察其框架是否可泛化。

### 3. The Format is the Filter: Scoring Format Fixes What an LLM Judge Can Express

| 字段 | 值 |
|------|------|
| 作者 | Lovedeep Gondara et al. |
| 年份 | 2026 |
| 链接 | https://arxiv.org/abs/2610.17158 |
| 类别 | Quality — LLM Judge 评分格式 |
| 实用价值 | ⭐⭐⭐⭐ (高) |

**方法摘要**：系统研究了 LLM-as-judge 数据筛选中评分格式（binary / 1-5 / 0-100 / comparison）对筛选效果的影响。在 15,406 条 UltraFeedback 候选数据上测试 5 种格式 × 3 个 judge 模型，微调 66 个模型进行验证。核心发现：0-100 评分实际仅利用 7-12 个有效等级；binary 判定导致 77-78% 平局；curation 数据优于随机选择，但各格式间无可检测的显著差异。提出 curation pipeline 应报告的 4 个量化指标。

**关键方法**：
- 5 种评分格式 × 3 种 judge 的大规模对照实验
- 有效评分等级分析（0-100 仅 7-12 级有效）
- 提出 pipeline 报告标准（4 个量化指标）

**实用价值评估**：对任何使用 LLM Judge 进行数据质量筛选的 pipeline 都有直接指导意义。核心启示：不必追求精细评分（0-100），粗粒度评分（如 1-5）在统计上等效但更高效。提出的 4 个报告指标可作为 pipeline 质量审计标准。对多语言数据筛选中的跨语言 judge 一致性研究也有参考价值。

### 4. Scaling Synthetic Pre-training Data and Evaluation for Indic LLMs

| 字段 | 值 |
|------|------|
| 作者 | NVIDIA + AI4Bharat |
| 年份 | 2026 |
| 链接 | https://arxiv.org/abs/2610.26006 |
| 类别 | Construction — 多语言合成预训练数据 |
| 实用价值 | ⭐⭐⭐⭐ (高) |

**方法摘要**：发布 Nemotron-Pretraining-Indic-v1，一个覆盖全部 22 种印度官方语言、约 2.83 万亿 token 的合成预训练语料库。同时推出 Indic-LLM-Eval-Suite，涵盖 chat、instruction following 等多维度的多语言评测基准。研究了多语言预训练中合成数据质量与数量之间的权衡关系。

**关键方法**：
- 大规模合成数据生成（2.83T tokens，22 种语言）
- 质量-数量 trade-off 实证分析
- 专用多语言评测 suite

**实用价值评估**：对多语言数据集构建具有极高参考价值。(1) 证明了合成数据在低资源语言预训练中的规模化可行性；(2) 质量-数量的 trade-off 分析可直接指导我们的多语言数据混合策略；(3) 评测框架可借鉴用于构建中文为中心的多语言评测。NVIDIA 的工程实践值得参考。

## 📊 趋势洞察

### 本次发现的关键趋势

1. **数据质量从"定性"走向"操作化"**  
   Serrano et al. 的工作标志着数据质量研究从"什么是好数据"转向"如何可操作地度量好数据"。Response ratio 这类简单、无需额外模型的指标，降低了质量筛选的门槛。

2. **LLM Judge 的方法论反思深化**  
   Gondara et al. 的评分格式实验揭示了一个反直觉事实：更精细的评分并不带来更好的筛选效果。这与我们之前观察到的"LLM-as-judge 过度自信"趋势一致，进一步支持了粗粒度+多 judge 聚合的实践策略。

3. **多语言合成数据进入"万亿 token"时代**  
   NVIDIA 的 Indic-v1 (2.83T tokens) 是迄今为止最大规模的多语言合成预训练语料之一。这验证了合成数据作为低资源语言数据补充的可行性，但也提出了质量控制的挑战。

4. **Agentic 数据筛选成为新兴子方向**  
   MetaCurate 的演化式 curation filter 代表了从静态规则到动态演化筛选的范式转移，专门面向 agent trajectory 数据。随着 LLM Agent 的普及，这一方向预计会快速增长。

### 与之前调研的对比分析

| 维度 | 前期趋势 | 本次增量变化 |
|------|----------|-------------|
| 质量评估 | 依赖模型分数（QuRating 等） | 向轻量级操作化指标转变（response ratio） |
| LLM Judge | 关注 judge 模型选择 | 深入到评分格式层面的方法论反思 |
| 多语言数据 | 筛选/分类为主 | 合成数据规模化（2.83T tokens） |
| 自动化筛选 | Multi-agent 协作（CuratorMAS） | 新增演化式 filter（MetaCurate） |

### 对多语言数据集构建的启示

1. **Response ratio 可作为多语言 SFT 数据的快速质量信号** — 无需翻译或跨语言模型，直接度量答案密度
2. **LLM Judge 评分格式应简化** — 对多语言场景尤其重要，因为跨语言 judge 的一致性本就较低，精细评分意义更小
3. **合成数据可作为低资源语言的规模化补充** — 但需要配套的质量-数量 trade-off 分析框架
4. **演化式筛选值得探索** — 可适配到多语言场景，通过跨语言分歧信号自动优化筛选规则
