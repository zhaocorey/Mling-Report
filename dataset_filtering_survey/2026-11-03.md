## 🆕 新增论文

### 1. Advancement or Acceleration? How Data Curation Improves LLM Training

- **作者**: Jiaxing Wang et al.
- **日期**: 2026-10-27
- **链接**: https://arxiv.org/abs/2610.36983
- **类别**: data_curation_theory

**摘要**: 形式化了数据筛选中 advancement（提升可达性能上限）与 acceleration（更快到达同一性能）的本质区别。核心发现：advancement 需要可修正的 train-target gap；当 baseline 训练目标与 target 一致时，任何 curation 策略都只能加速而非提升最终性能。提出 **Δ-test**——一个可在昂贵 curation 实验前计算的、基于 uncurated baseline 训练损失与目标损失差异的可观测指标。非零 Δ 预示着持续增益，Δ≈0 时增益随训练预算增长而消退。

**关键方法**:
- Δ-test（train-target discrepancy 预测 curation 收益）
- Analytic characterization of advancement conditions
- 跨多种 curation 方法的实验验证

**实用价值**: ⭐⭐⭐⭐⭐ — Δ-test 可直接用于多语言数据集筛选实验设计。在投入大规模 curation 前，先计算 Δ 值判断是否值得做。对我们评估"多语言数据混合是否能提升（而非仅仅加速）模型性能"有直接指导意义。

### 2. AQL-Lite: Enabling Efficient Knowledge Acquisition for Arabic LLMs via Data-Centric Continual Pretraining

- **作者**: Houssam Eddine Boukhalfa et al.
- **日期**: 2026-10-21
- **链接**: https://arxiv.org/abs/2610.30344
- **类别**: quality_filtering_pipeline

**摘要**: 针对阿拉伯语 LLM 适配的 quality-first curation 管线（AQL-Lite），包含结构清洗 → 启发式+模型过滤 → MSA 选择 → 去重的完整流程。结合 partial-parameter CPT（RS-LoRA + 最后 8 个 transformer block + embedding 层），在 1B token 预算下，筛选后数据比原始网页文本高 3.51 分。扩展到 40B MSA token 后，12B 模型在 OALL v2 上达到 75.3 分。

**关键方法**:
- Quality-first 多级 curation pipeline
- 部分参数 CPT（RS-LoRA adapters + layer-wise LR）
- 组件消融实验

**实用价值**: ⭐⭐⭐ — 为低资源语言适配提供了可复用的 curation pipeline 模板。结构清洗→多级过滤→语言选择→去重的流程可直接迁移到其他语言。部分参数 CPT 策略也有参考价值。

### 1. Marin 🔥

- **链接**: https://github.com/marin-community/marin
- **Stars**: ~2000
- **类别**: full_training_framework

**描述**: 开源基础模型研发框架，覆盖数据 curation、转换、筛选、分词、预训练、后训练和评估全流程。核心价值是 **open development**——从原始数据到最终模型的每一步都记录在案，失败实验也是记录的一部分。包含 Delphi 开放缩放套件（3e18 到 1e23 FLOPs），以及 25T token 的数据管线。

**与现有工具对比**: 不同于 NeMo Curator（仅数据筛选）或 DataComp-LM（benchmark），Marin 是端到端的训练框架，更接近 Open-Llama 但更强调 open process。

**实用价值**: ⭐⭐⭐⭐⭐ — **本期最值得关注的工具**。25T token 管线的数据筛选策略值得深入研究，open development 模式可作为我们多语言项目的参考。建议优先评估。

### 2. Data-Preparation-Bench (DataPrep-Bench)

- **链接**: https://github.com/OpenDCAI/Data-Preparation-Bench
- **Stars**: 241
- **类别**: data_quality_benchmark

**描述**: 首个统一的、面向下游效果的数据准备 benchmark，包含三个赛道：
- **Data Construction**: 原始数据 → SFT 数据
- **Data Selection**: 候选池 → 高价值子集
- **Data Quality Evaluation**: 预测数据集的下游效用

附带强 baseline：Data-Construction-Skill（技能驱动的 agent 构建）、10 种 selector 策略的统一框架、Distributional Alignment Score (DAS，免训练 MMD 质量估计器)。

**与现有工具对比**: 填补了 DataComp-LM（仅评估预训练数据）和 MMLU（仅评估模型）之间的空白——首次评估"数据准备工作流"本身的效果。

**实用价值**: ⭐⭐⭐⭐ — 可用于评估我们自己的数据筛选 pipeline 效果。DAS 指标（免训练的质量预测）特别有意思。需检查多语言覆盖度。

### 1. "There is no posttraining data commons"

- **作者**: Marin / Open Athena
- **日期**: 2026-10-15
- **链接**: https://openathena.ai/blog/
- **类别**: data_ecosystem_analysis

**摘要**: 分析了后训练数据（SFT/RLHF）与预训练数据的本质差异。核心论点：预训练数据可以被视为"公地"（commons），因为互联网规模文本具有公共品属性；但后训练数据是精心策划的产品，无法以同样方式共享。这一区分对数据策略有重要影响。

**实践价值**: 对多语言项目而言，后训练数据的构建策略需要不同于预训练的思路——不能简单依赖"开源共享"，需要自建高质量 SFT/RLHF 数据。

## 📊 趋势洞察

### 1. Curation 理论化加速
**Advancement or Acceleration** 标志着数据筛选领域从"经验主义"向"理论指导"的转变。Δ-test 提供了一个低成本、可操作的预判工具。这对我们的多语言工作有直接价值——在投入 curation 实验前，先判断"这件事值不值得做"。

### 2. 低资源语言获专项 curation 关注
AQL-Lite 展示了 quality-first pipeline 在低资源语言上的显著效果（+3.51 over raw text）。其结构清洗→多级过滤→语言选择的范式可迁移到其他语言。

### 3. 数据准备进入 Benchmark 化阶段
DataPrep-Bench 的出现意味着数据筛选/构建不再是"黑盒"工作——现在有标准化的评估框架。这将推动方法论的竞争和改进。

### 4. Agentic Curation 持续升温
从本期的 Agentic-Data-Platform 到近期的多篇论文，LLM agent 驱动的数据管理正在成为新范式。LangGraph 等多 agent 框架为复杂 curation 工作流提供了基础设施。

### 5. "数据 > 训练" 叙事进一步强化
Marin 框架将 25T token 数据管线作为核心资产开放，Open Athena 博客强调后训练数据的不可替代性——数据策划正在从"辅助"角色转变为"核心"角色。
