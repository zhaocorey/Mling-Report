### 1. OptiSelect: How does the Optimizer Shape Data Curriculum?

| 属性 | 内容 |
|------|------|
| 作者 | Simin Fan et al. |
| 年份 | 2026 |
| 链接 | https://arxiv.org/abs/2610.03432 |
| 类别 | selection |

**方法摘要：** 首次系统研究优化器如何影响在线数据选择。证明了基于符号的预条件器（Lion、Muon）会导致"判别力坍塌"（discriminability collapse），而自适应对角优化器（AdamW、Sophia）则具有严格更优的理论上界。推导出最优候选过采样比，并在 124M 和 720M 参数模型上验证。

**关键方法：**
- Optimizer-aware selection gain principle
- Discriminability collapse theory（符号优化器的判别力坍塌证明）
- Optimal oversampling ratio derivation

**实用价值：** ⭐⭐⭐⭐ — **高度实用**。揭示了一个被忽视的超参数交互：数据选择策略必须与优化器选择协同设计。对于使用 Lion/Muon 的训练系统需要特别注意。理论结果具有直接工程指导意义。

### 2. LESSER: Post-Training Data Selection with Output-Layer Gradients

| 属性 | 内容 |
|------|------|
| 作者 | Lyuxin David Zhang et al. |
| 年份 | 2026 |
| 链接 | https://arxiv.org/abs/2610.03702 |
| 类别 | selection |

**方法摘要：** 证明仅使用输出层梯度即可实现有效的数据选择，只需前向传播。作为即插即用包装器，将特征提取 FLOP 成本降低 9.7 倍（SFT）和 3.0 倍（RL），同时追踪全梯度选择的性能。发现输出层梯度和全梯度虽然对单个样本排序不同，但选择的批次具有对齐的梯度方向。

**关键方法：**
- Output-layer gradient approximation（仅用输出层梯度近似全梯度信号）
- Drop-in wrapper for gradient-based selection methods
- FLOP cost reduction analysis

**实用价值：** ⭐⭐⭐⭐⭐ — **极其重要**。解决了梯度数据选择方法的核心瓶颈——计算成本。9.7x FLOP 降低使其在大模型场景下可行。即插即用设计使其可集成到任何现有梯度选择框架中。

### 3. Beyond Data Schedule: Fast LLM Pretraining on Data Mixtures by Loss-Reweighting (LARE)

| 属性 | 内容 |
|------|------|
| 作者 | Jiazheng Li et al. |
| 年份 | 2026 |
| 链接 | https://arxiv.org/abs/2610.32141 |
| 类别 | mixing |

**方法摘要：** 提出 LARE（Loss-Adaptive Reweighting under fixed Exposure），在不改变采样混合比例的前提下，根据运行时 loss 统计动态调整领域权重。采用归一化逆平方根规则平衡 loss 尺度。在 1.5B 模型/240B tokens 上平均提升 +7.84pp，GSM8K 上 +17.06pp，MATH 上 +9.00pp。

**关键方法：**
- LARE loss-adaptive reweighting（固定曝光下的损失自适应重加权）
- Normalized inverse-square-root rule（归一化逆平方根规则）
- Fixed-exposure domain balancing

**实用价值：** ⭐⭐⭐⭐⭐ — **范式级贡献**。将"数据调度"问题转化为"损失重加权"问题，工程实现简单（只需修改 loss 权重），不改变数据加载逻辑。在数学推理上的巨大提升表明对 reasoning 能力培养特别有效。

### 4. No Model Required: Text Entropy Rate Filtering Mitigates Iterative Fine-Tuning Collapse

| 属性 | 内容 |
|------|------|
| 作者 | Lewis Mitchell et al. |
| 年份 | 2026 |
| 链接 | https://arxiv.org/abs/2610.01493 |
| 类别 | filtering |
| 发表 | **NeurIPS 2026** |

**方法摘要：** 使用非参数 Kontoyiannis 熵率估计器（h_k）进行训练数据过滤，完全从原始文本计算，无需任何模型。在六代 QLoRA 迭代微调崩溃实验（Llama-3.1-8B）中：+42% 唯一三元组、+30% 词汇量、-19% 重复率。显著优于基于 logprob 的过滤（后者无显著收益）。

**关键方法：**
- Kontoyiannis entropy rate estimator（基于匹配长度统计的熵率估计）
- Model-free text diversity filtering（完全无模型的文本多样性过滤）
- Iterative fine-tuning collapse mitigation

**实用价值：** ⭐⭐⭐⭐⭐ — **突破性方法**。无需 GPU 即可进行高质量数据过滤，极大降低了数据策划的计算门槛。对多语言数据尤为有价值——不需要为目标语言训练参考模型。NeurIPS 2026 接收增加了可信度。

### 5. Exact Unlearning After Data Curation

| 属性 | 内容 |
|------|------|
| 作者 | Priyank Jayraj |
| 年份 | 2026 |
| 链接 | https://arxiv.org/abs/2610.33426 |
| 类别 | deduplication |

**方法摘要：** 研究数据删除请求如何与基于去重的数据策划交互。提出"保留契约"（retention contracts）概念：服务承诺的未来删除范围决定了哪些被排除的数据仍然需要保留。为岭回归构建了有限精度特征以实现精确修复。在 1,001 条 AskUbuntu 记录上验证了 13,056 次删除步骤检查。

**关键方法：**
- Retention contract formalization（保留契约的形式化定义）
- Exact membership repair（精确成员修复）
- Conditional private-information minimum

**实用价值：** ⭐⭐⭐ — **理论价值 > 实践价值**。关注合规场景（GDPR 数据删除权）与数据去重的交叉，是偏小众但日益重要的方向。对多语言数据集构建的直接实用性有限，但对合规数据管道设计有参考意义。

### 6. Learning What Matters: End-to-End Adaptive Calibration Data Selection for LLM Pruning (OASIS)

| 属性 | 内容 |
|------|------|
| 作者 | Mengting Ai, Sirui Chen, Xinrui He et al. |
| 年份 | 2026 |
| 链接 | https://aclanthology.org/2026.findings-emnlp.510/ |
| 类别 | selection |
| 发表 | **EMNLP 2026 Findings** |

**方法摘要：** 首个端到端框架，通过可微分软掩码代理优化 LLM 剪枝的校准数据选择。揭示了上下文依赖的质量层次（Golden/Mediocre/Detrimental）。在 Llama 和 Qwen 系列模型上测试，提升了校准鲁棒性。

**关键方法：**
- OASIS differentiable soft-mask proxy（可微分软掩码代理）
- Context-dependent sample utility（上下文依赖的样本效用评估）

**实用价值：** ⭐⭐⭐ — **场景特定**。专注于模型剪枝的校准数据选择，对通用数据筛选场景适用性有限。但其"上下文依赖质量"的发现具有更广泛的启发意义——同一数据在不同上下文下可能是"黄金"或"毒药"。

### 7. The Effectiveness and Durability of Pretraining Data Filtering in Protein Language Models

| 属性 | 内容 |
|------|------|
| 作者 | Aaron Maiwald, Roderick McNeill et al. |
| 年份 | 2026 |
| 链接 | https://arxiv.org/abs/2610.26651 |
| 类别 | filtering |

**方法摘要：** 在 ESM-2 蛋白质语言模型（8M-3B 参数）上研究预训练过滤的有效性和持久性。过滤病毒蛋白会降低病毒目标上的性能，同时保持非病毒性能。效果随模型规模增大，但微调可以在适度成本（约 80 美元 H100）下恢复丢失的性能。

**关键方法：**
- Domain-specific filtering durability analysis（特定领域过滤持久性分析）
- Scale-dependent filtering effectiveness（规模依赖的过滤效果）
- Fine-tuning recovery cost analysis（微调恢复成本分析）

**实用价值：** ⭐⭐ — **领域特定**。虽然直接针对蛋白质模型，但"过滤持久性"和"微调恢复成本"的实验设计可迁移到 NLP 领域。核心启示：安全过滤的效果可能被后续微调轻易覆盖，这对安全对齐有重要意义。

| 属性 | 内容 |
|------|------|
| 链接 | https://openreview.net/forum?id=yMFKqSlAEI |

## 📊 趋势洞察

### 本次关键趋势

**1. 数据选择进入"效率优先"时代**
- LESSER（输出层梯度）和 OptiSelect（优化器感知）都在解决同一核心问题：如何让数据选择在大模型训练规模下实际可行
- 从"什么数据最好"转向"如何以 1/10 成本找到差不多好的数据"
- 这与工程中"近似即够用"的实用主义哲学一致

**2. 数据混合方法论成熟化**
- LARE 代表了一个重要转变：不改变数据采样，而是通过 loss 重加权来"虚拟"调整混合比例
- 相比传统的数据调度（改变加载顺序/比例），loss 重加权的工程实现更简单、更灵活
- 这暗示"数据调度"可能不是最优范式——直接在 loss 端操作更高效

**3. 无模型过滤方法崛起**
- 熵率估计器（NeurIPS 2026）证明了不依赖模型的高质量过滤是可行的
- 对多语言场景意义重大：无需为每种语言训练参考模型
- 可能重新定义"低资源语言数据策划"的可行方案

**4. 合规与遗忘成为新兴交叉方向**
- Exact Unlearning 研究删除权与去重的交互
- 蛋白质模型的过滤持久性分析揭示过滤效果可能被微调覆盖
- 随着 AI 法规收紧，"可审计的数据管道"将成为刚需

### 与之前对比

| 方向 | 上期状态 | 本次状态 | 趋势判断 |
|------|----------|----------|----------|
| 数据选择 | 热点持续 | **效率化转向** | ⬆️ 更务实 |
| 数据混合 | 综述化 | **精细化** | ⬆️ 方法论成熟 |
| 无模型过滤 | 萌芽 | **突破验证** | ⬆️⬆️ 值得重点关注 |
| 合规/遗忘 | 边缘 | **新兴** | ➡️ 关注但不急 |
| 模型剪枝数据 | 空白 | **首篇** | ➡️ 小众方向 |

### 对多语言数据集构建的启示

1. **熵率过滤（论文 #4）可直接应用**：对低资源语言文本进行无模型质量过滤，无需训练语言特定的参考模型
2. **LARE（论文 #3）简化多语言混合**：不同语言域的损失尺度不同，LARE 的自适应重加权可自动平衡
3. **LESSER（论文 #2）降低多语言选择成本**：多语言数据池更大，梯度选择方法的计算效率尤为关键
4. **"质量多维性"（博客）警示**：多语言场景下不能用英语中心的单一质量标准评估所有语言数据
