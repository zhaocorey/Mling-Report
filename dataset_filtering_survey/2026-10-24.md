## 🆕 新增论文

### 1. Pick the Mixture, Not the Samples: Combinatorial Data Selection for LLMs
- **作者/来源：** arXiv 2610.14028 (2026-09)
- **链接：** https://arxiv.org/abs/2610.14028
- **方法摘要：** 提出 Combinatorial Data Selection (CDS) 框架，将数据选择分为归因(attribution)和选择(selection)两阶段。Mixture-then-Select 算法先决定各域取样数量再域内排序，比强基线提升 20-54%。理论证明选择差距与选择大小线性相关，与池大小无关。
- **关键方法：** Combinatorial Data Selection、Mixture-then-Select
- **实用价值：** ⭐⭐⭐⭐⭐ 对多语言数据集混合比例优化极具参考价值，将域级配比与样本级选择解耦是关键创新

### 2. Demystifying Data Organization for Enhanced LLM Training
- **作者/来源：** Microsoft Research (2026-05)
- **链接：** https://arxiv.org/abs/2605.30334
- **方法摘要：** 系统研究数据组织（排序、分块、课程）对 LLM 训练的影响。提出 4 条优化准则：Boundary Sharpening（避免域边界模糊）、Cyclic Scheduling（周期性数据重排）、Curriculum Continuity（课程连续性）、Local Diversity（局部多样性）。配套 STR/SAW 排序方法在预训练和 SFT 均有效。
- **关键方法：** STR (Shortest Token Ratio)、SAW (Sliding Attention Window)
- **实用价值：** ⭐⭐⭐⭐⭐ 对训练数据编排有直接指导意义，4 条准则可作为 data pipeline 设计原则

### 3. PUFFER: Incremental Fuzzy Deduplication for Continuously Evolving Corpora
- **作者/来源：** arXiv 2608.28622 (2026-08)
- **链接：** https://arxiv.org/abs/2608.28622
- **方法摘要：** 面向持续演化语料的增量模糊去重方法。传统批量去重与流式数据管线不匹配，PUFFER 设计增量索引结构，在不牺牲召回率的前提下实现低延迟的近似去重。
- **关键方法：** 增量索引、模糊去重、流式处理
- **实用价值：** ⭐⭐⭐⭐ 对持续爬取的多语言网页语料特别有价值，解决增量数据与已有语料去重的实际痛点

### 4. Layer-Aware Representation Filtering (LARF): Purifying Finetuning Data to Preserve LLM Safety Alignment
- **作者/来源：** arXiv 2507.18631 (2025-07)
- **链接：** https://arxiv.org/abs/2507.18631 | [代码](https://github.com/LLLeoLi/LARF)
- **方法摘要：** 识别 LLM 中的安全敏感层（safety-critical layers），利用其表征检测后训练数据中含安全退化特征的样本。移除这些数据后可缓解微调导致的安全对齐退化。
- **关键方法：** 层重要性分析、安全表征过滤
- **实用价值：** ⭐⭐⭐⭐ 对安全对齐场景的数据筛选有独特视角，多语言安全数据过滤可借鉴

### 5. FinerWeb-10BT: Refining Web Data with LLM-Based Line-Level Filtering
- **作者/来源：** arXiv 2501.07314 (2025-01)
- **链接：** https://arxiv.org/abs/2501.07314
- **方法摘要：** 用 GPT-4o mini 标注行级质量标签，训练 DeBERTa-v3 分类器扩展到 10B token 子集。过滤后模型在 HellaSwag 上更高准确率，且用少 25% 数据即可达到同等性能。
- **关键方法：** LLM 标注蒸馏、行级过滤、分类器训练
- **实用价值：** ⭐⭐⭐⭐⭐ 行级过滤比文档级更精细，对多语言网页数据质量提升有直接参考意义

### 8. UDS: Utility-Diversity Aware Online Batch Selection for LLM Supervised Fine-tuning
- **作者/来源：** arXiv 2510.16882 (2025-10)
- **链接：** https://arxiv.org/abs/2510.16882 | [代码](https://github.com/gfyddha/UDS)
- **方法摘要：** 在线批次选择框架，利用 logits 矩阵核范数同时捕获数据效用和样本内多样性，通过低维嵌入对比估计样本间多样性。无需外部资源，显著减少训练时间。
- **关键方法：** 核范数效用度量、嵌入多样性估计、在线批次选择
- **实用价值：** ⭐⭐⭐⭐⭐ 实用性强，在线选择避免了全量预处理，对大规模 SFT 数据选择有直接应用价值

- **关键方法：** 梯度对齐、自适应课程学习、RL 数据选择
- **实用价值：** ⭐⭐⭐⭐ 对 RLHF/GRPO 训练数据选择有创新视角，验证集驱动的梯度对齐方法简洁有效

### 10. From Parameters to Data (P2D): A Task-Parameter-Guided Fine-Tuning Pipeline for Efficient LLM Alignment

## 📊 趋势洞察

### 本期关键趋势

1. **组合优化取代样本排序：** CDS 的 Mixture-then-Select 范式将域级配比与样本级排序解耦，性能提升 20-54%，标志着数据选择从"排好序取 top-k"走向"先选混合比例再选样本"。

2. **数据组织成为新维度：** Microsoft 的 data-efficacy 工作表明，数据排序/分块/课程策略对训练效果的影响不亚于数据选择本身。4 条组织准则（Boundary Sharpening / Cyclic Scheduling / Curriculum Continuity / Local Diversity）可直接指导 pipeline 设计。

3. **安全-质量双轴过滤：** LARF 和 Surprise Masking 分别从安全对齐和隐私保护角度切入数据过滤，与传统的效用/多样性维度形成正交补充。

4. **ICLR 2026 集群效应：** 3 篇 ICLR 2026 论文入选（Why Less Is More / Fine-Grained Preferences / 200× Less Data），反映数据策展领域正从工程实践走向理论化。

5. **多语言基础设施升级：** HPLT 3.0（30T token / 200 语言）是当前最大开放多语言语料，其完整开源管线对多语言数据集构建有标杆意义。

### 对多语言数据集构建的启示

- **HPLT 3.0 的管线**可作为多语言数据处理的参考架构
- **CDS 的组合选择**特别适合多语言场景下的语言配比优化
- **FinerWeb 的行级过滤**可提升多语言网页数据的细粒度质量控制
- **PUFFER 的增量去重**适合持续爬取的多语言语料流式处理
- **Diversity Without Labels** 对无标注多语言数据的筛选有直接应用价值
