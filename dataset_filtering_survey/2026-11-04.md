### 1. Advancement or Acceleration? How Data Curation Improves LLM Training

- **作者：** Unknown (arXiv 2610.36983)
- **年份：** 2026-10
- **链接：** https://arxiv.org/abs/2610.36983
- **类别：** Data Curation（理论）
- **方法摘要：** 本文形式化了数据策划中两个常被混淆的概念：**advancement**（提升可达性能上限）和 **acceleration**（以更少步数达到相同性能）。作者证明 advancement 需要存在可修正的 train-target gap，并提出 **Delta-test** 作为可观测的策划收益预测器。
- **关键方法：** Delta-test（可观测预测器）
- **实用价值：** ⭐⭐⭐⭐ — 对评估"数据策划到底有没有用"提供了理论框架。在决定是否投入额外计算做数据策划时，Delta-test 可作为快速判据。**推荐纳入方法论工具箱。**

### 2. AQL-Lite: Enabling Efficient Knowledge Acquisition for Arabic LLMs via Data-Centric Continual Pretraining

- **作者：** Unknown (arXiv 2610.30344)
- **年份：** 2026-10
- **链接：** https://arxiv.org/abs/2610.30344
- **类别：** Multilingual / Filtering / Construction
- **方法摘要：** 面向阿拉伯语 LLM 的质量优先数据策划 pipeline，包含结构清洗、启发式+模型过滤、MSA（现代标准阿拉伯语）选择、去重四个阶段。配合部分参数 CPT（Continual Pre-Training）方案，在 52% 的 wall-clock 时间内恢复了 94% 的全参数 CPT 增益。扩展至 40B MSA tokens 规模验证。
- **关键方法：** 分层过滤 pipeline + 部分参数 CPT
- **实用价值：** ⭐⭐⭐⭐⭐ — **对多语言数据集构建有直接参考价值。** 其分层过滤策略（结构→启发式→模型→语言→去重）可作为多语言 pipeline 的模板。部分参数 CPT 的效率发现也很实用。

### 3. TiKMiX: Efficient Semi-Dynamic Data Mixture via Data Influence for LLM Pre-training

- **作者：** ACL 2026
- **年份：** 2026
- **链接：** https://aclanthology.org/2026.acl-long.261/
- **类别：** Mixing
- **方法摘要：** 提出半动态数据混合框架，基于 **influence ranking invariance** 的观察：训练过程中数据影响力的排序相对稳定。利用这一性质，在静态混合（次优）和全动态混合（高计算成本）之间找到了效率平衡点。
- **关键方法：** Influence ranking invariance + semi-dynamic scheduling
- **实用价值：** ⭐⭐⭐⭐ — 解决了数据混合的核心痛点（动态太贵、静态太差）。如果能验证跨语言场景下的 ranking invariance，可直接用于多语言混合比例调度。

### 4. DaMo: Data Mixing Optimizer in Fine-tuning Multimodal LLMs for Mobile Phone Agents

- **作者：** ACL 2026 Findings
- **年份：** 2026
- **链接：** https://aclanthology.org/2026.findings-acl.1439/
- **类别：** Mixing（多模态 / Agent）
- **方法摘要：** 针对手机端多模态 Agent 的 SFT 数据混合优化器。解决多任务 SFT 场景下的最优训练数据配比问题，在多模态 agent 的特定领域进行验证。
- **关键方法：** 数据混合比例优化（多任务 SFT）
- **实用价值：** ⭐⭐⭐ — 领域较窄（手机端多模态 agent），但方法论可借鉴。如果构建多模态多语言 agent 数据可参考其混合优化思路。

### 5. Optimizing Training Data Diversity with DataSpinner: An LLM-driven Curator-Agent Approach

- **作者：** IEEE (11661205)
- **年份：** 2026
- **链接：** https://ieeexplore.ieee.org/abstract/document/11661205/
- **类别：** Curation / Filtering
- **方法摘要：** 将数据集多样性优化建模为序贯决策问题，使用 LLM 驱动的 curator agent 执行。核心关注 **distributional collapse** 问题——训练语料在迭代过滤后收敛到狭窄的低多样性子集。
- **关键方法：** LLM-as-agent + 序贯多样性优化
- **实用价值：** ⭐⭐⭐⭐ — distributional collapse 是高质量过滤的常见陷阱。该工具思路对多语言数据筛选尤为重要（避免过度过滤导致语言/领域多样性丧失）。

### 6. Scalable Entity-Centric Data Filtration for LLM Pretraining

- **作者：** IEEE (11723055)
- **年份：** 2026
- **链接：** https://ieeexplore.ieee.org/abstract/document/11723055/
- **类别：** Filtering
- **方法摘要：** 以实体（entity）作为紧凑语义锚点进行数据过滤。通过实体级别的冗余检测和信息密度评估，识别并移除预训练语料中的冗余或低信息密度文档。
- **关键方法：** Entity-centric filtering + 信息密度评估
- **实用价值：** ⭐⭐⭐ — 实体中心过滤在多语言场景有潜力（不同语言的实体覆盖可比较），但需要验证实体识别在低资源语言上的效果。

### 7. DADFS: A Dynamic Adaptive Data Filtering and Sampling Framework for Optimized Fine-Tuning of Large Language Models

- **作者：** IEEE (10984505)
- **年份：** 2025-05
- **链接：** https://ieeexplore.ieee.org/stamp/stamp.jsp?arnumber=10984505
- **类别：** Filtering / Sampling
- **方法摘要：** 整合动态自适应过滤（Dynamic Adaptive Filtering）、自适应数据采样（Adaptive Data Sampling）和数据混合（Proportional Weighting）的统一框架。在 LoRA + PEFT 框架内实现，面向 LLM 微调场景。
- **关键方法：** 动态过滤 + 自适应采样 + 比例加权混合
- **实用价值：** ⭐⭐⭐⭐ — 将过滤、采样、混合三个通常独立的步骤统一在一个框架内，工程实践价值高。LoRA/PEFT 集成使其对资源受限场景友好。

## 📊 趋势洞察

### 本次发现的关键趋势

1. **数据混合从"配比搜索"走向"半动态调度"：** TiKMiX 的 influence ranking invariance 发现是一个重要的效率突破，说明不需要每个 step 都重新计算最优配比，按关键节点更新即可。

2. **数据策划的理论化加速：** Advancement vs Acceleration 的形式化定义，以及 Delta-test 的提出，标志着领域从"试错"走向"可预测"。

3. **多语言 pipeline 持续产出案例：** AQL-Lite 的分层过滤策略为阿拉伯语场景提供了完整参考。其部分参数 CPT 的效率发现（94% gain in 52% time）对任何多语言扩展都有参考价值。

4. **LLM-as-Curator 模式扩散：** DataSpinner 将 LLM 作为策划 agent 做多样性优化，延续了"用 LLM 策划 LLM 数据"的自举范式。

### 与之前调研的对比

| 维度 | 前期趋势 | 本期增量 |
|------|----------|----------|
| 热点领域 | Selection/Coreset | Mixing + Filtering 并重 |
| 方法论 | 在线重加权 | 半动态混合 + 理论框架 |
| 多语言 | MuRating、JQL | AQL-Lite（阿拉伯语） |
| 工具生态 | Data-Juicer、NeMo | Marin（全 pipeline） |

### 对多语言数据集构建的启示

- **AQL-Lite 的分层过滤 pipeline 可直接借鉴**：结构清洗 → 启发式过滤 → 模型过滤 → 语言选择 → 去重，适用于任何低资源语言扩展
- **TiKMiX 的 semi-dynamic 策略**可用于多语言混合比例的动态调度，避免全动态重计算的成本
- **DataSpinner 的多样性保护机制**对防止多语言数据过度过滤尤为关键

1. **AQL-Lite pipeline** ⭐⭐⭐⭐⭐ — 其分层过滤 + 部分参数 CPT 方案是多语言扩展的现成模板，建议精读并复现核心实验

### 建议纳入 pipeline 的工具
