### 1. Rethinking Data Selection: The Importance of Coverage over Difficulty in Generative Fine-Tuning

| 属性 | 值 |
|------|-----|
| **作者** | Unknown |
| **年份** | 2026 |
| **发表** | OpenReview |
| **链接** | https://openreview.net/forum?id=g1DiK2Yi4j |
| **类别** | sampling |

**方法摘要**：该工作对 LLM fine-tuning 中的数据选择方法进行了系统性反思。核心发现是：现有 sophisticated 选择方法相对 random sampling 的性能优势很弱，coverage（使用目标模型的 embeddings）比 difficulty 更能预测选择效果。提出了基于 target model embeddings 的 coverage-based selection 方法，证明在 generative fine-tuning 场景下，数据的多样性覆盖远比挑选"难题"更重要。

**关键方法**：coverage-based selection、target model embeddings、difficulty vs coverage 对比分析

**实用价值**：⭐⭐⭐⭐ — 对多语言数据集构建有直接指导意义。在多语言场景下，追求语言/领域覆盖比追求单一样本质量评分更可能获得好的模型表现。与之前 propella-1 的多维质量标注形成互补：先覆盖后筛选。

### 4. Register Always Matters: Analysis of LLM Pretraining Data Through the Lens of Language Variation

| 属性 | 值 |
|------|-----|
| **作者** | Unknown |
| **年份** | 2026 |
| **发表** | arXiv |
| **链接** | https://arxiv.org/abs/2504.01542 |
| **类别** | filtering |

**方法摘要**：首个将语料语言学中的 register（语域/文体）概念引入 LLM 预训练数据策划的研究。系统分析不同文体（新闻、评论、博客、论坛等）对模型性能的影响。核心发现：(1) 新闻类 register 效果不佳；(2) Opinion 类（评论、博客）收益显著；(3) 组合高性能 register 可带来大幅改进。这为数据配比提供了文体维度的理论依据。

**关键方法**：register-based data curation、genre analysis、compositional register mixing

**实用价值**：⭐⭐⭐⭐⭐ — **对多语言数据集构建有重大参考价值**。多语言数据天然是多 register 的（新闻、Wiki、论坛、社交媒体等），本文提供了基于文体分析的数据配比方法论。可与 FineWeb-2 的 register 标注、propella-1 的多维标注结合使用。建议重点精读。

## 📊 趋势洞察

### 本次发现的关键趋势

**1. "Coverage > Difficulty" 范式得到更多验证**
- "Rethinking Data Selection" 直接证明了在 generative fine-tuning 中 coverage 比 difficulty 更重要
- 这与之前 "Removing Noise, not Finding Gold"（⭐⭐⭐⭐⭐）的发现高度一致：数据选择的核心价值在于去噪而非淘金
- 对多语言数据集构建的启示：**优先确保语言/领域/文体的覆盖完整性，再在覆盖框架内做质量筛选**

**2. Register（文体/语域）成为数据策划新维度**
- "Register Always Matters" 首次将语料语言学的 register 概念系统化引入 LLM 数据策划
- 发现新闻类数据效果不佳、Opinion 类（评论/博客）收益大——这与多语言预训练的经验一致（Wikipedia 不等于好的多语言数据）
- 可结合 FineWeb-2 的 register 标注和 propella-1 的多维标注构建 register-aware 的多语言数据 pipeline

**3. 数据工程化/工具化持续加速**
- 5 个新工具中，curation-discipline 和 data-juicer-multimodal-curation 代表了两种不同方向：前者关注 agent 安全，后者关注多模态+云存储集成
- DatasetForge 的 SQLite registry 设计反映了社区对数据集版本管理的迫切需求

**4. 多语言/低资源语言关注持续**
- awesome-vietnamese-llm-dataset 是继此前多个语言专项索引后的又一个
- Human+AI multilingual guardrails 论文直接面向多语言安全数据策划

### 与之前调研的对比分析

| 维度 | 上期趋势 | 本期变化 |
|------|----------|----------|
| 数据选择方法 | 模型内信号（梯度/激活）主导 | coverage 重要性被独立验证 |
| 数据质量 | 多维质量标注（propella-1） | register/文体维度补充 |
| 工具生态 | Data-Juicer、NeMo Curator 为主 | 更多垂直化工具出现 |
| 多语言 | MuRating、MixMinMatch | 越南语索引 + multilingual guardrails |

### 对多语言数据集构建的启示

1. **Register-aware 数据配比**：不同文体对模型能力的影响差异巨大。建议在多语言数据 pipeline 中增加 register 分类步骤，避免过度依赖新闻类数据
2. **Coverage-first 策略**：先按语言×register×domain 构建覆盖矩阵，再在每个 cell 内做质量过滤
3. **Human+AI 混合评估**：对低资源语言，纯 LLM-as-Judge 不可靠，需要引入 human-in-the-loop 的质量评估
