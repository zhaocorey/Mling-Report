## 🆕 新增论文（5篇）

### 1. Pretraining Data Statistics Shape the Phases of Learning Entity Comparison in Language Models

- **作者**: Yik Siu Chan, Jing Huang, Yanai Elazar, Atticus Geiger
- **日期**: 2026-11-12
- **链接**: https://arxiv.org/abs/2611.xxxxx
- **类别**: data_analysis（数据分析）
- **方法摘要**: 研究预训练数据统计特征如何塑造语言模型学习实体比较的阶段性行为。分析了数据组成和分布如何影响 LM 的学习动态，揭示了训练数据中实体分布的统计规律与模型能力涌现之间的关系。
- **关键方法**: 学习阶段分析、数据分布与模型行为关联研究
- **实用价值**: ⭐⭐ 偏理论分析，对理解数据分布影响有参考意义，但不直接提供可操作的 curation 方法

### 2. Human or Synthetic? What a Fixed Budget Buys for Post-Training

- **作者**: Shourik Banerjee, Ethan Mendes, Mohit Raghavendra, Wei Xu, Alan Ritter
- **日期**: 2026-11-12
- **链接**: https://arxiv.org/abs/2611.xxxxx
- **类别**: data_quality（数据质量）
- **方法摘要**: 在固定预算约束下系统比较人类标注数据与合成数据对 LLM 后训练的效果。提供了何时应投入人力标注、何时可用合成数据替代的实证指导。研究发现混合策略在不同任务类型上表现差异显著。
- **关键方法**: 预算约束下的数据源权衡实验、human vs synthetic 对比框架
- **实用价值**: ⭐⭐⭐⭐ 直接回应多语言数据集构建中的核心问题——资源有限时如何平衡人工标注与合成数据

### 3. Data Schedules and Learning Rate Schedules Should Be Designed Together

- **作者**: Haodong Wen, Kairong Luo, Tingkai Yan, Wenguang Chen, Kaifeng Lyu
- **日期**: 2026-10-28
- **链接**: https://arxiv.org/abs/2510.xxxxx
- **类别**: curriculum_learning（课程学习/数据调度）
- **方法摘要**: 证明 LLM 中训练（mid-training）阶段的数据调度（curriculum）和学习率调度是耦合的，应联合设计。朴素地组合各自独立设计的调度方案会导致次优性能，提出了协同设计的原则和方法。
- **关键方法**: 数据-学习率联合调度、协同优化框架
- **实用价值**: ⭐⭐⭐ 重要发现——数据排序策略需与训练超参协同考虑，对 pipeline 中 curriculum 设计有直接指导意义

### 4. A Comprehensive Framework for All Stages of Large-Model Training: From Data and Tokenization, through Pretraining, to Post-Training Alignment

- **作者**: Xiangjing An, Zhibin Jiao, Aiting Chen
- **日期**: 2026-10-24
- **链接**: https://arxiv.org/abs/2510.xxxxx
- **类别**: survey（综述/框架）
- **方法摘要**: 提出覆盖 LLM 训练全阶段的综合框架，包括数据 curation、分词、预训练和后训练对齐。为数据质量在 pipeline 各阶段的传递提供统一指导原则。
- **关键方法**: 全链路框架、跨阶段数据质量传递
- **实用价值**: ⭐⭐⭐ 作为参考框架有价值，特别是数据质量在不同训练阶段的衔接方面

### 5. Agentic Data Engineering for LLMs: System Design and a Controlled Empirical Study

- **作者**: Ruomeng Ding, Qianli Shen, Zhaoyang Han, Meixin Chen, Daoyuan Chen, Yaliang Li
- **日期**: 2026-10-09
- **链接**: https://arxiv.org/abs/2510.xxxxx
- **类别**: data_pipeline（数据管线/自动化）
- **方法摘要**: 提出 Agent 驱动的数据工程系统设计，让 AI Agent 自动化数据 curation、质量评估和 pipeline 编排。包含自动化 vs 人工 curation 的对照实验评估，展示了 Agent 在数据工程中的潜力和局限。
- **关键方法**: Agent 驱动的数据工程自动化、多 Agent 协作 curation
- **实用价值**: ⭐⭐⭐⭐ 新兴范式——与我们自身的 Agent 驱动调研模式高度共鸣，对构建自动化数据 pipeline 有直接参考价值
