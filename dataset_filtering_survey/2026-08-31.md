### 1. GRACE: Gradient-guided Coreset Selection for LLM Unlearning

| 字段 | 内容 |
|------|------|
| **作者** | Praveen Bushipaka, Andrea D'Angelo, Lucia Passaro, Tommaso Cucinotta |
| **年份** | 2026 |
| **链接** | https://arxiv.org/abs/2608.28361v1 |
| **发表** | 2026-08-28 · EMNLP Findings 2026 |
| **类别** | Data Selection（数据选择） |

**方法摘要：**
本文提出 GRACE（Gradient-guided Coreset Selection for Unlearning），一种面向 LLM 选择性遗忘的梯度引导核集选择方法。该方法从种子示例计算"遗忘方向"，然后使用非负正交匹配追踪（NNOMP）选择紧凑的遗忘核集，使其梯度近似该方向。为保护模型效用，在投影去除遗忘方向后选择保留示例。与已有 GRACE 系列工作（Dynamic Coreset / Gradient-aligned Reasoning）不同，本文聚焦遗忘而非训练效率。

**关键方法：**
- 遗忘方向向量：从种子示例计算目标梯度方向
- 非负正交匹配追踪（NNOMP）：选择梯度近似最优的核集
- 正交投影保留策略：在去除遗忘方向后选择 retain 样本

**实用价值评估：** ⭐⭐⭐⭐（高）
- 已被 EMNLP Findings 2026 接收，方法可靠
- 核集选择方法在遗忘场景的首次系统性应用，扩展了 coreset 方法论的应用边界
- 对多语言模型有直接价值：当需要"遗忘"特定语言/领域的有害知识时，可用此方法选择性去除
- **多语言启示**：可用于多语言模型的安全对齐——选择性遗忘特定语言的有害内容，同时保留其他语言能力

### 2. Instruction Quality Matters: Refining Instructions for Effective Preference Learning

| 字段 | 内容 |
|------|------|
| **作者** | Seohyeong Lee, Hwaran Lee, Buru Chang |
| **年份** | 2026 |
| **链接** | https://arxiv.org/abs/2608.26779v1 |
| **发表** | 2026-08-27 |
| **类别** | Data Curation（数据策划） |

**方法摘要：**
本文揭示指令质量是偏好学习中的隐藏瓶颈。提出一个指令精炼流水线：首先利用奖励信号识别弱指令，然后通过基于评分标准的 LLM 反馈对其进行修订，在不丢弃样本的情况下提升偏好数据质量。实验表明，指令精炼提高了可达到的响应质量上限，并与以响应为中心的偏好数据策划方法互补。

**关键方法：**
- 奖励信号驱动的弱指令识别
- 评分标准引导的 LLM 反馈修订
- 指令精炼 + 响应策划的组合策略

**实用价值评估：** ⭐⭐⭐⭐（高）
- **揭示了偏好数据策划的新维度**——当前大多数工作聚焦响应质量，本文证明指令质量同等重要
- 不丢弃样本而是修订，提高数据利用效率（对低资源语言尤为重要）
- 与 DPO/ORPO 等偏好优化方法直接兼容
- **多语言启示**：多语言偏好数据中，指令质量差异可能更为显著（翻译质量、文化适配等），本文方法可作为多语言偏好数据的质量提升工具

### 3. VISA: Agentic Self-Evolving Data Synthesis for Multimodal Instruction Following

| 字段 | 内容 |
|------|------|
| **作者** | Min Zeng, Guanxin Tan, Libin Cen, Yafei Wen, Rui Hu, Liuyang Bian, Xiaolong Chen, Xiaoxin Chen |
| **年份** | 2026 |
| **链接** | https://arxiv.org/abs/2608.26013v2 |
| **发表** | 2026-08-26 |
| **类别** | Synthetic Data（合成数据） |

**方法摘要：**
本文提出 VISA（Visual Instruction Synthesis Agent），一种将多模态指令数据合成推进到"自进化"范式的 agentic 框架。不同于传统的"一次生成-过滤"范式，VISA 利用多轮迭代自我进化，从失败样本、验证器反馈和目标模型错误中学习，逐步提升合成数据质量。每轮迭代都整合了验证反馈信号来指导下一步的数据生成策略。

**关键方法：**
- 迭代自进化框架：超越一次性生成
- 多源验证反馈：失败样本、验证器结果、目标模型错误
- Agentic 数据合成：LLM 作为数据合成代理

**实用价值评估：** ⭐⭐⭐⭐（高）
- 代表了合成数据方法论的最新范式——从静态生成到动态自进化
- 多源反馈机制设计值得借鉴，可用于任何合成数据流水线的质量迭代
- 虽然聚焦多模态，但其"自进化"思想可直接迁移到纯文本多语言数据合成
- **多语言启示**：多语言指令数据合成可借鉴 VISA 的迭代反馈机制，用目标模型在特定语言上的错误信号指导合成数据质量提升

### 4. When Teacher Guidance Misleads: Reward-Aligned On-Policy Distillation

| 字段 | 内容 |
|------|------|
| **作者** | See arXiv |
| **年份** | 2026 |
| **链接** | https://arxiv.org/abs/2608.27960v1 |
| **发表** | 2026-08-28 |
| **类别** | Data Curation（数据策划） |

**方法摘要：**
本文研究 LLM 在策略蒸馏（On-Policy Distillation, OPD）中教师指导误导学生训练的情况。提出基于奖励对齐的蒸馏数据过滤方法，识别并移除误导性的教师输出。核心思想是：并非所有教师生成的数据都值得学生学习，需要选择性过滤"有毒"的教学数据。

**关键方法：**
- 奖励对齐过滤：用奖励信号评估教师输出质量
- 误导性输出检测：识别会损害学生模型的教师数据
- 选择性蒸馏数据策划

**实用价值评估：** ⭐⭐⭐（中）
- 与已有的 R2-OPD（Beyond Imitation）互补，后者聚焦推理进展过滤，本文聚焦奖励对齐
- 对知识蒸馏场景有直接参考价值
- 方法论较通用，可迁移到其他数据过滤场景
- **多语言启示**：在多语言蒸馏中（大语言模型 → 小语言模型），教师在不同语言上的质量差异可能导致选择性误导，本文方法可用于识别哪些语言的蒸馏数据需要过滤

### 5. PinSieve: Production Selective VLM Serving and a Governed Memory Flywheel for Enterprise Content-Quality Triage

| 字段 | 内容 |
|------|------|
| **作者** | Chuqing Gao, Yuanfang Song, Jonathan Zhang, Yifan Wu, Vishwakarma Singh, Qinglong Zeng, Andrey Gusev |
| **年份** | 2026 |
| **链接** | https://arxiv.org/abs/2608.24040v1 |
| **发表** | 2026-08-25 · KDD 2026 Workshop on Enterprise AI Agents |
| **类别** | Data Curation（数据策划） |

**方法摘要：**
本文是一个工业级生产案例研究，描述了一个大规模内容质量流水线，包含一个数据策划 Agent（Data Curation Agent），该 Agent 使用有界的 proposal-verifier 循环，覆盖代表性、不确定性、时效性和新鲜审查回放等策略。特色包括选择性 VLM 服务用于灰区内容分类，以及受治理的记忆飞轮用于在选择性反馈下进行持续数据策划。

**关键方法：**
- 有界 proposal-verifier 循环：多维度数据质量评估
- 选择性 VLM 服务：仅对"灰区"内容启用昂贵的 VLM 判断
- 受治理的记忆飞轮：持续学习和改进的数据策划策略

**实用价值评估：** ⭐⭐⭐（中）
- 工业级案例研究，展示了数据策划 Agent 在生产环境中的实际部署
- "选择性服务"思想（简单样本用轻量模型，复杂样本用重量模型）对降低计算成本有普遍参考价值
- 飞轮机制对构建可持续运行的数据质量系统有启发
- **多语言启示**：灰区内容分类在多语言场景更为常见（文化差异导致的模糊内容），选择性 VLM 服务策略可降低多语言内容审核成本

## 📊 趋势洞察

### 本次发现的关键趋势

1. **Coreset 方法论的应用边界持续扩展**：从训练效率优化（GRACE-Dynamic）→ 推理数据策划（GRACE-Reasoning）→ 选择性遗忘（GRACE-Unlearning），核集选择方法正在覆盖 LLM 生命周期的更多阶段

2. **数据策划从"响应中心"向"指令中心"转移**：Instruction Quality Matters 首次系统性地将注意力从响应质量转向指令质量，揭示了偏好数据策划中被忽视的维度

3. **Agentic 数据合成范式深化**：VISA 代表了从"一次生成-过滤"到"多轮自进化"的范式转移，验证反馈驱动的迭代合成正在成为主流

4. **工业级数据策划 Agent 开始落地**：PinSieve 展示了数据策划 Agent 在生产环境中的部署，"proposal-verifier 循环"和"受治理飞轮"是工程化关键模式

### 与之前调研的对比分析

| 维度 | 历史趋势 | 本次增量 |
|------|----------|----------|
| **热点领域** | 数据选择（Selection）持续为最大热点 | 数据策划（Curation）占 50%，选择仅占 17% |
| **方法论** | Coreset 进入"模型内信号"时代 | Coreset 扩展到遗忘场景 |

**类别分布变化**：相比 08-28 报告（Filtering/Mixing/Sampling 各 33%），本期集中在 Curation（50%）和 Synthetic Data（33%），反映研究关注点从"选择什么数据"向"如何策划和合成高质量数据"转移。

### 对多语言数据集构建的启示

1. **遗忘导向核集选择**（GRACE-Unlearning）为多语言模型安全对齐提供了新工具——可选择性遗忘特定语言的有害知识
2. **指令质量精炼**（Instruction Quality Matters）对多语言偏好数据构建尤为重要——翻译质量和文化适配导致的指令差异可能是多语言对齐的隐性瓶颈
3. **自进化合成范式**（VISA）可迁移到多语言数据合成——用目标模型在特定语言上的错误信号驱动迭代质量提升

## 💡 建议

### 值得深入研究的方向

1. **⭐⭐⭐⭐ Coreset 方法在遗忘/安全场景的应用** — GRACE-Unlearning 开辟了 coreset 方法论的新应用方向，建议关注其在多语言安全对齐中的潜力
2. **⭐⭐⭐⭐ 指令质量对偏好学习的影响** — 这是一个被严重忽视的维度，建议进一步调研指令质量评估和精炼的方法论

### 建议纳入 pipeline 的工具/方法

- **指令精炼流水线**（Instruction Quality Matters 的方法）：可直接用于提升多语言偏好数据质量，成本低、效果可验证
- **选择性 VLM 服务模式**（PinSieve 的灰区分类策略）：对大规模多语言内容质量评估有成本优化参考价值

### 可忽略或低优先级的工作

- **From Documents to Reasoning（金融数值推理）**：领域过于特定，除非项目有金融多语言需求，否则优先级低
- **PinSieve 的具体实现细节**：作为工业案例有参考价值，但其系统设计高度依赖特定业务场景，迁移性有限
