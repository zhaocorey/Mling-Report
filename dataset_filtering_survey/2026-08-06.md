## 🆕 新增论文

### 📂 数据过滤 (Filtering) — 3篇

#### 1. The Data-Quality Illusion: Rethinking Classifier-Based Quality Filtering for LLM Pretraining
- **年份**: 2026
- **链接**: https://openreview.net/forum?id=vSBACt34gS
- **摘要**: 从根本上挑战了分类器质量过滤（CQF）在 LLM 预训练中的有效性。研究发现 CQF 实际上是在高质量数据集自身上进行隐式质量过滤，倾向于加权与高质量集相似的数据，而非真正识别低质量数据。揭示了分类器方法的根本性局限。
- **关键方法**: classifier-based quality filtering 理论分析、implicit quality filtering 机制揭示
- **实用价值**: ⭐⭐⭐⭐⭐ — 对所有使用分类器过滤预训练数据的团队具有警示意义。需要重新审视 CQF 是否真正提升了数据质量，还是仅仅做了分布偏移。
- **类别**: filtering

#### 2. CPQS-Tuning: A Model Self-Perception-Based Data Filtering Algorithm for Efficient Instruction Fine-Tuning
- **年份**: 2026
- **链接**: https://openreview.net/forum?id=d57KvqmcBA
- **摘要**: 利用 LLM 自身的隐藏状态变异性（hidden state variability）作为质量评估信号，过滤指令微调数据中的低质量和冗余数据。无需外部标注器，让模型"自我感知"数据质量。
- **关键方法**: model self-perception、hidden state variability、自感知数据过滤
- **实用价值**: ⭐⭐⭐⭐ — 提供了一种无需外部质量标注器的过滤方案，对资源受限场景特别有价值。
- **类别**: filtering

#### 3. Pharmacist: Safety Alignment Data Curation for Large Language Models Against Harmful Fine-Tuning
- **年份**: 2026
- **链接**: https://arxiv.org/abs/2510.10085
- **摘要**: 从对齐数据中选择高质量且安全关键的子集，以防御有害微调攻击，同时降低训练成本。兼容 Vaccine、RepNoise、Booster、T-Vaccine 等多种防御方法。
- **关键方法**: safety-critical subset selection、alignment data curation、harmful fine-tuning defense
- **实用价值**: ⭐⭐⭐⭐ — 将数据选择与安全防御结合，开辟了安全数据策划的新方向。
- **类别**: filtering

### 📂 数据采样/课程学习 (Sampling/Curriculum) — 7篇

#### 4. DUMP: Distribution-Level Curriculum Learning for RL-based LLM Post-training
- **年份**: 2026
- **链接**: https://openreview.net/forum?id=ILjb8TnGJa
- **摘要**: 针对 RL 后训练中训练数据来自多个分布的场景，提出分布级课程学习。使用 UCB（Upper Confidence Bound）方法进行课程采样，解决多分布数据下的课程设计难题。
- **关键方法**: distribution-level curriculum、UCB sampling、RL post-training
- **实用价值**: ⭐⭐⭐⭐ — 直接解决 RLHF/GRPO 训练中多源数据混合的调度问题，实用性强。
- **类别**: sampling

#### 5. Multi-Adversary Group Distributionally Robust Optimization (GDRO) for LLM Reasoning
- **年份**: 2026
- **链接**: https://arxiv.org/abs/2601.19280
- **摘要**: 提出 Multi-Adversary GDRO 框架用于 RL 后训练，包含动态难度分类器。Prompt-GDRO 使用 EMA 去偏的 bandit 采样器，Rollout-GDRO 使用影子价格控制器。在 GRPO 基线上分别取得 +10.6% 和 +10.1% 的 pass@8 提升。
- **关键方法**: online difficulty classifier、multiplicative-weights bandit、shadow-price controller
- **实用价值**: ⭐⭐⭐⭐⭐ — 显著提升推理 RL 训练效果，两种方案灵活适配不同场景。
- **类别**: sampling

#### 6. Difficulty Is Not Enough: Curriculum Learning for LLMs Fine-tuning Must Consider Utility (DUCL)
- **年份**: 2026
- **链接**: https://ojs.aaai.org/index.php/AAAI/article/view/40400 (AAAI 2026)
- **摘要**: 提出 Difficulty-Utility Curriculum Learning（DUCL），在课程学习中同时考虑样本的难度和效用。引入 Difficulty-Utility Evaluation（DUE）评分和 Window Ordering 调度策略。
- **关键方法**: difficulty-utility scoring、window ordering、curriculum learning
- **实用价值**: ⭐⭐⭐⭐ — 指出仅靠难度排序的课程学习不够，需要同时考虑样本对模型能力提升的效用。
- **类别**: sampling

## 📊 趋势洞察

### 1. RL Post-Training 数据策略成为主战场

本期 7/22 篇论文（32%）聚焦 RL 后训练阶段的数据调度，远超 SFT 数据选择。这与当前 RLHF/GRPO 训练的普及直接相关：
- **Multi-Adversary GDRO** 在 GRPO 上取得 +10% 提升，验证了精细化数据调度的价值
- **DUMP** 首次系统解决多分布数据的课程问题
- **Rollout Strategies Survey** 为该领域提供了首个系统性分类框架

**启示**: 团队在 RL 训练框架中应集成动态数据调度模块，而非沿用静态数据混合策略。

### 2. 数据归因（Data Attribution）进入工程化拐点

5篇归因论文形成完整方法谱：
- **LoRIF**: 低秩近似解决可扩展性瓶颈
- **Concept Influence**: 可解释性概念提升归因质量
- **Mechanistic Data Attribution**: 机制层面的精细归因
- **DataDignity**: LM-head 分析的新角度

**启示**: LoRIF 的低秩方法最接近工程化落地，值得优先评估。

### 3. 质量过滤范式面临根本性反思

**The Data-Quality Illusion** 是本期最重要的论文之一，揭示分类器质量过滤本质上是在做分布匹配而非质量筛选。结合 **CPQS-Tuning** 的模型自感知过滤，暗示了质量过滤的下一步方向：
- 从外部标注器 → 模型内在信号
- 从静态过滤 → 动态自适应

### 4. 合成数据 + 课程学习的融合

**MathMixup** 和 **Exploring Agentic Data Engineering** 代表了数据构建的新趋势：不再将合成数据生成和数据选择视为独立步骤，而是端到端优化。

### 5. 安全数据策划的兴起

**Pharmacist** 开辟了全新方向——在对齐数据中选择安全关键子集以防御有害微调。这对部署场景的安全合规有直接影响。
