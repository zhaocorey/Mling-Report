## 📊 趋势洞察

### 本次发现的关键趋势

1. **数据选择的「场景化」加速**
   - 从通用选择方法转向特定场景：蒸馏数据选择（What Matters in On-Policy Distillation）、量化校准选择（Target-Aware Calibration）、RL 后训练任务选择（BOTS）、代码模型选择（Code-LLM Influence）
   - 启示：未来数据选择方法需要更紧密地与下游任务/训练阶段耦合

2. **数据混合方法论的「第三条路」**
   - 传统：基于领域比例的静态混合（RegMix、BiMix）
   - 近期：在线动态调整（OP-Mix、HDS）
   - **新增**：因果推断框架（CausalMix）、模型内信号驱动（Rethinking from LLM Perspective）、约束满足（DynaMiCS）
   - 启示：混合方法正在从「调比例」进化为「理解因果+适应约束」

3. **Agent 自动化数据策划进入验证阶段**
   - "Can Generalist Agents Automate Data Curation?" 证明 Agent 可达专家水平
   - FlowPipe 提出 LLM 增强的 pipeline 自动构建
   - 启示：数据策划工程师的角色可能从「执行者」转向「设计者/审核者」

4. **过滤策略的「辩证反思」**
   - "A Bitter Lesson" 质疑激进过滤
   - 情感偏差分析揭示过滤的隐性副作用
   - 罗马尼亚语工作展示低资源场景下过滤+多样性的平衡
   - 启示：过滤不是银弹，需要「过滤什么、保留什么、为何保留」的系统思考

### 对多语言数据集构建的启示

1. ⭐ **"Mix, Don't Tune" 直接验证了数据混合策略的优越性**：在资源有限时，优先投资数据混合而非超参搜索。这对我们的多语言 pipeline 有直接指导意义。
2. **低资源语言过滤需要多样性保护**：罗马尼亚语工作（#18）表明，质量过滤的同时必须保留多样性，否则低资源语言的数据稀缺问题会加剧。
3. **过滤偏差审计不可忽视**：情感偏差工作（#17）提醒我们，任何过滤 pipeline 都可能引入隐性偏见。建议在多语言 pipeline 中加入偏见审计步骤。
4. **Agent 自动化策划可加速语言覆盖扩展**：如果能用 Agent 自动化数据策划（#15），则可以更低成本地扩展到新语言。
