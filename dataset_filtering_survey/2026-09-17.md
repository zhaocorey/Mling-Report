**方法摘要：** 首个全面覆盖文本去重方法的 IEEE 综述论文。系统梳理了从传统 n-gram/Jaccard 语法匹配到基于嵌入的语义去重的完整技术谱系。涵盖 MinHash、SimHash、局部敏感哈希（LSH）等经典方法，以及基于 transformer 编码器的语义相似度去重。讨论了对 LLM 训练数据质量和模型性能的直接影响。

**实用价值：** 🟢 **高**。为我们评估和选择去重策略提供了权威参考框架。结合我们之前调研的 SemHash-LLM、Lshbloom、SEDD 等工具，该综述可作为去重方案选型的理论基础。**建议精读**。

### 2. Fine PT-PT Web: A High-Quality 41 Billion Tokens Data Collection of the European Portuguese Web

| 属性 | 内容 |
|------|------|
| 作者 | 未详 |

**方法摘要：** 针对欧洲葡萄牙语（PT-PT）这一区域性语言变体，从 411 TB 原始网页数据中构建了 41B token 的高质量语料库。创新点在于引入了"后抓取区块移除"（post-scraping block removing）步骤，在过滤前去除模板和行内重复，使文档产出率提升 19%。整合了语言识别、加权模糊去重和神经质量分类器。

**实用价值：** 🟢 **高**。这是继 GermanWeb、ptbr-cpt-data-ablation 之后又一个区域性语言 pipeline 案例。其"后抓取区块移除"技巧对我们处理中文网页数据中的模板噪声有直接参考价值。框架可复用于其他低资源语言。

### 4. STAFF: Speculative Coreset Selection for Task-Specific Fine-tuning

| 属性 | 内容 |
|------|------|
| 作者 | 未详 |
| 年份 | 2026 |
| 链接 | https://arxiv.org/abs/2410.01296 |
| 类别 | 选择（Selection）— Coreset 效率优化 |
| 相关度 | ⭐⭐⭐⭐ (8/10) |

**方法摘要：** 提出"投机式"coreset 选择策略：利用同一模型家族的小模型高效估算数据分值，然后在目标大模型上验证。相比 SOTA 方法提升最高 54.3%，同时减少 70.5% 的选择开销。在 20% 剪枝率下可超越全数据集微调效果。

**关键方法：** 小模型→大模型的分值推测（类似 speculative decoding 思想）；同族模型间的分值迁移

**实用价值：** 🟢 **高**。这个"投机选择"思路非常巧妙——用 1B 模型估算 7B 模型的数据选择，大幅降低计算成本。与之前调研的 proxy model 方法（Can Small Training Runs Reliably Guide Data Curation?）相比，STAFF 明确了"同族模型"这个关键约束。**建议精读并实验验证**。

### 5. Learning from the Right Rollouts: Data Attribution for PPO-based LLM Post-Training (I-PPO)

| 属性 | 内容 |
|------|------|
| 作者 | 未详 |
| 年份 | 2026 |
| 链接 | https://arxiv.org/abs/2604.01597 |
| 类别 | 数据归因（Data Attribution）— RL 后训练 |
| 相关度 | ⭐⭐⭐⭐ (8/10) |

**方法摘要：** Influence-Guided PPO (I-PPO) 首次将数据归因整合进 RL 后训练流程。通过梯度近似计算每个 episode 的 influence score，识别并消除与验证集梯度反对齐的 episode。作为内在的早停机制，有效减少不忠实的 CoT 推理。

**关键方法：** 基于梯度的 episode influence 计算；反对齐 episode 过滤；内在早停

**实用价值：** 🟢 **高**。RL 后训练的数据质量问题是当前热点，I-PPO 提供了一种原理性的解决方案。与之前调研的 DRIFT（on-policy data attribution）和 LZE（learning-zone energy）形成互补——前者关注 SFT，I-PPO 专注 PPO。**建议精读，尤其关注 gradient approximation 的效率**。

### 本次发现的关键趋势

1. **Coreset 方法进入"效率优先"阶段**：STAFF 的"投机选择"（小模型估大模型）代表了 coreset 研究的新方向——不再追求最优选择质量，而是在质量-效率间找到实用平衡点。这与 speculative decoding 在推理加速中的思路高度一致。

2. **数据归因从 SFT 扩展到 RL**：I-PPO 将 influence-based 数据归因引入 PPO 后训练，标志着数据归因技术覆盖了 LLM 训练的完整生命周期（预训练 → SFT → RLHF）。

3. **去重领域获得系统性总结**：IEEE 综述论文的出现意味着文本去重从"工程实践"上升为"学科方向"。语义去重（而非简单的 n-gram 匹配）将成为下一阶段主流。

4. **区域性语言 pipeline 持续涌现**：Fine PT-PT Web 延续了 GermanWeb、ptbr 等区域语言 pipeline 的趋势，每个新 pipeline 都在方法论上有微创新（如本次的"后抓取区块移除"）。

### 与之前调研的对比分析

| 方向 | 历史报告重点 | 本次增量 | 变化信号 |
|------|-------------|---------|---------|
| Coreset 选择 | GRACE、MADS、BLADE 等模型内信号方法 | STAFF 的效率优化、新综述 | 从"选择质量"转向"选择效率" |
| 去重 | SemHash-LLM、Lshbloom 等工具 | IEEE 综合综述 | 从工具创新到方法论总结 |

### 对多语言数据集构建的启示

1. **去重策略升级**：IEEE 综述可作为我们重新评估去重方案的理论框架。建议在现有 n-gram 去重基础上引入语义层，参考 SemHash-LLM 的多粒度方案。

2. **投机选择可迁移**：STAFF 的方法可迁移到多语言场景——用小语言模型估算数据对大语言模型的价值，加速多语言数据选择。

3. **区域语言 pipeline 模板化**：Fine PT-PT Web 的"后抓取区块移除"技巧可纳入我们的通用 pipeline，特别适用于中文互联网数据中普遍存在的模板噪声。

4. **RL 阶段数据质量控制**：随着越来越多团队采用 RLHF/RLVR，I-PPO 的 episode-level 数据归因方法将成为保障多语言 RL 训练质量的重要工具。
