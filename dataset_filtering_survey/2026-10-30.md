## 🆕 新增论文

### 1. CuratorMAS: Automating Dataset Curation via Multi-Agent Orchestration

| 字段 | 内容 |
|------|------|
| **作者** | Yixin Zhang, Wenjie Feng |
| **机构** | University of Science and Technology of China (USTC) |
| **年份** | 2026 |
| **链接** | https://arxiv.org/abs/2610.07075 |
| **类别** | Data Curation / Multi-Agent |

**方法摘要：**
CuratorMAS 是一个多智能体协作框架，通过编排四个核心 Agent（Explorer、Researcher、Evaluator、Filter）来自动化数据策划全流程。Explorer 负责数据发现与采集，Researcher 分析数据特征与分布，Evaluator 评估质量与适用性，Filter 执行最终过滤。整个策划流程被分解为五个可编程执行阶段，支持灵活定制。实验表明，该框架可将噪声率降低高达 **36.03 个百分点**，下游模型 F1 分数提升高达 **8.88 个百分点**。

**关键方法：**
- Multi-Agent 分工协作（4 Agent 架构）
- 五阶段可编程 Pipeline
- 自动化质量评估与过滤决策

**实用价值评估：** ⭐⭐⭐⭐
- ✅ 多 Agent 协作模式适合大规模多语言数据策划的复杂流程
- ✅ 可编程阶段设计允许针对不同语言/领域定制 Pipeline
- ⚠️ 需要关注实际部署成本和 Agent 间通信开销
- 🔗 与已报道工作互补：CuratorKIT（后训练数据生成）、DataMaster（意图驱动选择）侧重不同环节

### 2. Fisher-Guided Submodular Data Selection for Continual Pre-Training of Large Language Models

| 字段 | 内容 |
|------|------|
| **作者** | Zhenghao Zhao, Gaowen Liu, Zhiling Lan, Yan Yan |
| **机构** | University of Illinois Chicago; Cisco Research |
| **年份** | 2026 |
| **链接** | https://arxiv.org/abs/2610.02593 |
| **类别** | Data Selection / Continual Pre-Training |

**方法摘要：**
提出基于 Fisher 信息矩阵的持续预训练数据选择方法。核心创新是将候选样本的梯度分解为两个正交组件：**anchor**（保护已有能力，防止灾难性遗忘）和 **frontier**（获取新知识，推动能力边界）。在此基础上，利用子模函数优化实现高效数据子集选择。在 TinyLlama-1.1B 和 Llama-3.1-8B 的医疗领域持续预训练实验中，仅用 **1B 精选 tokens** 即超越 10B tokens 的 replay 策略，实现了 **10× token 效率优势**。

**关键方法：**
- Fisher 信息梯度分解（anchor + frontier）
- 子模函数优化数据子集选择
- 持续预训练场景下的知识保护与获取平衡

**实用价值评估：** ⭐⭐⭐⭐⭐
- ✅ **对多语言数据集构建高度相关**：增量添加新语言本质上是持续预训练问题
- ✅ 10× token 效率在计算资源受限的多语言场景下价值极大
- ✅ anchor/frontier 分解思路可迁移到多语言场景——anchor 保护高资源语言能力，frontier 拓展低资源语言覆盖
- ✅ 子模优化框架可扩展到大规模数据
- 🔗 与此前报道的 Capacity-Aware Mixture Law、Middo 等方法形成持续预训练方法论组合

## 📊 趋势洞察

### 本次发现的关键趋势

1. **Multi-Agent 数据策划进入实用化阶段**
   - CuratorMAS 将数据策划分解为多 Agent 协作任务，标志着从「单工具过滤」到「智能体协作策划」的范式升级
   - 与此前报道的 DataMaster（单 Agent 意图解释）和 Autodata（单 Agent 合成）相比，Multi-Agent 架构更适合处理多语言数据策划的复杂决策链

2. **持续预训练数据选择成为独立研究方向**
   - Fisher-Guided 方法首次在 CPT 场景下实现了 anchor/frontier 梯度的显式分解
   - 此前多数数据选择方法假设从零预训练或微调，CPT 场景（增量添加新领域/新语言）的特殊需求开始被关注

### 与之前调研的对比分析

| 维度 | 历史报告趋势 | 本期新增 |
|------|-------------|---------|
| **Multi-Agent** | DataMaster、Autodata 等单 Agent 方法 | CuratorMAS 引入多 Agent 编排 |
| **CPT 数据选择** | Capacity-Aware Mixture Law、Middo 等混合比例方法 | Fisher-Guided 提出梯度分解新范式 |
| **效率目标** | 多为减少训练数据量 | 扩展到减少持续训练增量数据量 |
| **工具/博客** | 每期均有新工具和新博客 | 本期为零，可能为搜索窗口间隙 |

### 对多语言数据集构建的启示

1. **CuratorMAS 的多 Agent 架构可迁移到多语言策划**：
   - Explorer Agent → 多语言数据源发现
   - Researcher Agent → 语言分布与质量分析
   - Evaluator Agent → 跨语言质量评估
   - Filter Agent → 语言感知过滤

2. **Fisher-Guided anchor/frontier 分解直接适用于多语言增量训练**：
   - 在向现有多语言模型添加新语言时，anchor 保护已有语言能力，frontier 高效拓展新语言
   - 10× token 效率意味着用更少的目标语言数据达到同等效果
