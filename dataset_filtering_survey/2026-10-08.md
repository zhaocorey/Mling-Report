### 1. CuratorMAS: Automating Dataset Curation via Multi-Agent Orchestration

- **作者**: Yixin Zhang, Wenjie Feng (USTC)
- **年份**: 2026
- **链接**: [arXiv:2610.07075](https://arxiv.org/abs/2610.07075)
- **提交日期**: 2026-10-05
- **类别**: data_curation_automation

**摘要**: 高质量数据集对可靠的机器学习至关重要，但数据策划仍然成本高昂且难以跨领域泛化。现有方法通常依赖手动设计的启发式规则或模型相关信号。本文提出 CuratorMAS，一个多智能体协作框架，编排多个 Agent 来评估和策划高质量数据集。CuratorMAS 将复杂的策划过程分解为五个可编程执行阶段（数据集探索→领域知识检索→评估标准推导→指标计算与过滤→进化总结），形成可并行化的工作流。

**关键方法**:
- 五阶段可编程执行管线：探索 → 检索 → 评估 → 过滤 → 进化
- 多 Agent 协作编排（非单 Agent 顺序执行）
- 在线领域知识检索增强评估过程
- 进化模块总结评估结果并更新技能库

**实验结果**: 噪声率降低最高 36.03 个百分点，下游模型 F1 提升最高 8.88 个百分点

**实用价值**: ⭐⭐⭐⭐ — 多 Agent 编排范式是数据策划自动化的新方向，与上期 ReScraper 的"小模型替代规则栈"形成互补——CuratorMAS 关注"如何自动化决策流程"，ReScraper 关注"如何高效执行清洗"。目前尚未开源代码，需等待实际可用性验证。对多语言数据构建而言，其领域知识检索模块值得关注：能否自动获取低资源语言的领域知识来指导过滤。

### 2. Fisher-Guided Submodular Data Selection for Continual Pre-Training of Large Language Models

- **作者**: Zhenghao Zhao, Gaowen Liu, Zhiling Lan, Yan Yan (UIC + Cisco Research)
- **年份**: 2026
- **链接**: [arXiv:2610.02593](https://arxiv.org/abs/2610.02593)
- **提交日期**: 2026-10-01
- **类别**: data_selection / continual_pretraining

**摘要**: 在大规模语言模型训练中，数据选择已成为核心瓶颈——网络级语料噪声大且 token 预算有限。在持续预训练（CPT）中，这更是一个遗忘控制问题：选择不当的目标领域语料可能覆盖预训练检查点中编码的能力。现有 CPT 实践要么使用与参数无关的标量评分（如困惑度），要么通过大量通用领域 replay token 来缓解遗忘。本文揭示了一个参数空间机制：基于 loss 的选择导致预训练模型已承诺的高 Fisher 坐标上的 Fisher 对角线下降，从而引发灾难性遗忘。由此提出 Fisher 感知的 CPT 数据选择器，将每个候选样本的梯度分解为 anchor 分量（度量对已承诺参数方向的扰动）和 frontier 分量（度量在无约束低 Fisher 子空间中的更新能力）。

**关键方法**:
- Fisher 信息对角线分析：揭示 loss-based 选择导致遗忘的参数空间机制
- Anchor-Frontier 梯度分解：锚定已学能力 + 探索新能力
- Log-determinant 子模目标函数：聚合 anchor/frontier 信号
- 可扩展的流式数据选择管线：单次遍历优化

**实验结果**: 在 TinyLlama-1.1B 和 Llama-3.1-8B 的医学 CPT 上，**1B 选中 token 在适应性和遗忘控制两方面均优于 replay 策略的 10B token**——10× token 效率优势

**实用价值**: ⭐⭐⭐⭐⭐ — 本期最具价值的工作。对多语言持续预训练直接适用：当我们在通用 LLM 基础上做领域/语言适应时，Fisher anchor-frontier 分解可自然扩展到语言维度，帮助选择既不遗忘通用能力又高效学习目标领域的数据。10× token 效率优势意味着可以大幅降低 CPT 成本。已发表在 cs.LG，方法论成熟度较高。

### 趋势分析

| 趋势方向 | 本期信号 | 历史对比 |
|---------|---------|---------|
| 自动化数据策划 | CuratorMAS 多 Agent 编排 | 上期 ReScraper 小模型替代规则栈；从"执行层"走向"决策层" |

| 持续预训练优化 | CPT 专用数据选择器 | 此前 CPT 主要依赖 replay + 数据混合；缺少理论驱动的选择方法 |

### 与上期（10-03）对比

- **方法论深度提升**: 上期偏工具/工程层面（ReScraper、websieve），本期偏理论/方法论层面（Fisher 几何、多 Agent 编排）
- **CPT 成为热点**: Fisher-Guided 论文直接针对 CPT 场景，反映了领域从"从头预训练"向"持续适应"的转变
- **多 Agent 范式延续**: 继上期 CuratorKIT 被历史报告收录后，CuratorMAS 进一步推动了 Agent 在数据策划中的应用

### 对多语言数据集构建的启示

1. **Fisher-Guided 选择可迁移到多语言 CPT**: 在多语言持续预训练中，anchor 分量可保护通用语言能力，frontier 分量可高效学习目标语言/领域数据
2. **多 Agent 编排有望解决多语言策划复杂性**: 多语言数据策划涉及语言平衡、领域覆盖、质量过滤等多个维度，CuratorMAS 的分阶段编排范式天然适合处理这种多目标优化
3. **token 效率对低资源语言尤为重要**: 低资源语言的可用数据有限，高效的数据选择方法可以最大化有限数据的价值
