### 1. GEM: Geometric Entropy Mixing for Optimal LLM Data Curation

| 字段 | 内容 |
|------|------|
| 作者 | Yue Min et al. |
| 年份/会议 | 2026-05 / ICML 2026 Poster |
| 链接 | https://arxiv.org/abs/2605.26121 |
| 类别 | **Mixing**（数据混合） |

**方法摘要：**
GEM 将数据策划重新表述为超球面上的变分问题，并引入混合平衡正则化器（mixing-balance regularizer）。通过 MM（Majorization-Minimization）算法对抗聚类坍塌，发现平衡的语义结构。提出几何影响分数（Geometric Influence Score, GIS）用于可解释的分类体系生成。与 DoReMi 和 RegMix 集成后，在 1.1B 参数模型上最高提升下游精度 1.2%。

**关键方法：**
- 超球面变分优化 + 混合平衡正则化
- MM 算法防止语义聚类坍塌
- GIS 分数实现可解释的数据分类

**实用价值评估：⭐⭐⭐⭐**
几何视角的数据混合是一个全新方向。GIS 分数为数据配方提供了可解释性，这对多语言数据集的领域平衡和语言覆盖规划非常有价值。ICML 2026 接收说明理论扎实。值得与现有 DoReMi/RegMix pipeline 集成测试。

### 2. CurateEvo: Data-Curation Evolving for Agentic Post-Training

| 字段 | 内容 |
|------|------|
| 作者 | Multiple authors |
| 年份 | 2026-07 |
| 链接 | https://arxiv.org/abs/2607.06140 |
| 类别 | **Curation / Selection**（动态策划） |

**方法摘要：**
CurateEvo 提出失败驱动的动态演化框架，专为 Agent 后训练设计数据策划策略。将策划策略表示为可执行代码，利用失败轨迹（failed trajectories）迭代重写。将原始语料转化为 SFT 数据、RL 数据和推理时记忆库（inference-time memory bank）。在 ACEBench-Agent、BFCL-V4 和 tau2-Bench 上平均提升 3.2 和 2.7 分。

**关键方法：**
- 策划策略即代码（Strategy-as-Code），可进化重写
- 失败轨迹驱动的迭代优化
- 三通道输出：SFT + RL + Memory Bank

**实用价值评估：⭐⭐⭐**
Agent 后训练是一个新兴场景，其数据需求与传统 SFT/RLHF 显著不同。"策略即代码"的理念有趣，但目前偏向 Agent 领域，与多语言数据集构建的直接关联较弱。如果未来扩展到通用 LLM 训练，价值会更大。可保持关注。

> ⚠️ **注意：** 此论文与已报告的 "CurateEvo: Evolutionary Evaluation for Data Curation"（arXiv:2507.00317）是**不同论文**（不同标题、不同 arXiv ID），前者聚焦 Agentic Post-Training，后者聚焦 Evolutionary Evaluation。

### 3. QuaDMix: Quality-Diversity Balanced Data Selection for Efficient LLM Pretraining

| 字段 | 内容 |
|------|------|
| 作者 | Multiple authors |
| 年份 | 2026-04 |
| 链接 | https://arxiv.org/abs/2504.16511 |
| 类别 | **Mixing / Selection**（数据混合 + 选择） |

**方法摘要：**
QuaDMix 是一个统一的数据选择框架，联合优化预训练数据的质量（Quality）和多样性（Diversity）。使用多重质量标准衡量质量，通过领域分类衡量多样性，引入参数化采样函数并通过 LightGBM 优化。在多个基准测试上平均提升 7.2%。

**关键方法：**
- 质量-多样性联合优化（Quality-Diversity Trade-off）
- 参数化采样函数 + LightGBM 超参优化
- 多标准质量评估 + 领域分类多样性度量

**实用价值评估：⭐⭐⭐⭐**
质量与多样性的平衡是多语言数据集构建的核心挑战之一。7.2% 的平均提升幅度显著。LightGBM 优化的参数化采样函数易于工程化落地。建议深入阅读其多标准质量评估模块，可能直接适配到我们的多语言质量过滤 pipeline。

### 4. Understanding Data Influence With Differential Approximation (Diff-In)

| 字段 | 内容 |
|------|------|
| 作者 | Multiple authors |
| 年份 | 2026 |
| 链接 | http://ieeexplore.ieee.org/stamp/stamp.jsp?tp=&arnumber=11421676 |
| 类别 | **Selection / Quality**（数据选择 / 影响函数） |

**方法摘要：**
Diff-In 通过在连续学习步骤之间累积影响力差异来近似样本影响力，使用二阶近似实现。在保持与一阶方法相当的计算复杂度的同时，达到更低的近似误差。可扩展到数百万数据点的视觉-语言预训练场景。

**关键方法：**
- 差分近似（Differential Approximation）：逐步累积影响力差异
- 二阶近似达到一阶计算复杂度
- 百万级数据点可扩展性

**实用价值评估：⭐⭐⭐⭐**
影响力函数的可扩展性一直是其在 LLM 训练中落地的瓶颈。Diff-In 在不牺牲精度的前提下大幅降低计算成本，对于大规模多语言数据集的样本估值非常有用。如果能与现有的在线数据选择框架结合，可以实现更精准的数据价值评估。

### 5. Data Scarcity and Model Sparsity: Mixtures-of-Experts Overfit More to Repeated Data

| 字段 | 内容 |
|------|------|
| 作者 | Multiple authors |
| 年份 | 2026-09-10 |
| 链接 | https://arxiv.org/abs/2609.11917 |
| 类别 | **Quality**（数据质量 / 重复效应） |

**方法摘要：**
本文系统性研究了数据重复对 MoE（Mixture-of-Experts）与 Dense 模型的不同影响。实验规模从 80M 到 1B active / 8.5B total 参数。发现 MoE 模型在数据重复下退化更快：4x 重复即开始性能下降，而 Dense 模型可容忍到 8x。专家特化（expert specialization）与过拟合高度相关。Dropout 和 masking 正则化可部分缓解，但没有方法能完全匹配全唯一数据的性能。

**关键方法：**
- 控制实验：系统性测试不同重复倍数（2x/4x/8x/16x）对 MoE vs Dense 的影响
- 专家特化分析：揭示 MoE 过拟合的内在机制
- 正则化缓解实验：Dropout、masking 等方法的效果评估

**实用价值评估：⭐⭐⭐⭐⭐**
这对多语言数据集构建有**直接且重要**的启示。多语言场景中，低资源语言的数据往往被重复使用。本文的量化结论（MoE 4x 即退化）为数据重复使用设定了明确的安全阈值。如果目标模型是 MoE 架构，必须在数据 pipeline 中严格控制重复，优先扩充唯一数据而非重复已有数据。

## 📊 趋势洞察

### 本次发现的关键趋势

**1. 几何方法进入数据混合领域**
GEM 将数据混合从启发式搜索提升到超球面变分优化，代表了数据混合方法论从"经验调参"向"理论驱动"的转变。GIS 分数提供了传统方法缺乏的可解释性。

**2. 质量-多样性联合优化成为共识**
QuaDMix 进一步确认了单一质量标准的局限性。联合优化质量与多样性的范式正在成为数据选择的新标准，这与多语言数据集构建中"覆盖率 vs 质量"的权衡高度契合。

**3. 影响力函数的工程化落地加速**
Diff-In 解决了影响力函数的计算瓶颈问题。二阶近似以一阶成本实现，使得百万级数据集的样本估值变得可行。

**4. MoE 架构对数据质量的特殊要求首次被量化**
Data Scarcity 论文提供了 MoE vs Dense 模型对数据重复的容忍度量化对比，填补了该领域的空白。

### 与之前调研的对比分析

| 方向 | 前期状态 | 本期变化 |
|------|---------|---------|
| 数据混合 | 已有综述（Data Mixing Survey）+ 多种方法（DoReMi, RegMix, OP-Mix） | GEM 引入几何视角，QuaDMix 强化质量-多样性联合优化 |
| 动态策划 | EVODATA、ADAPT 等工作建立基础 | CurateEvo 扩展到 Agent 后训练场景 |
| 影响力函数 | Diff-In 之前，可扩展性仍是瓶颈 | Diff-In 提供实用的二阶近似方案 |
| 数据重复/质量 | 已知重复有害，但缺乏量化 | MoE 4x 阈值提供了明确的操作指导 |

### 对多语言数据集构建的启示

1. **数据重复安全阈值：** 如果目标模型为 MoE，每种语言的数据重复不应超过 4x；Dense 模型可放宽至 8x。这对低资源语言的采样策略有直接指导意义。
2. **质量-多样性平衡：** 在多语言场景中，QuaDMix 的联合优化框架可用于平衡各语言的数据质量和覆盖多样性，避免高质量语言数据压倒低质量但必要的低资源语言数据。
3. **几何影响分数（GIS）：** 可用于多语言数据的语义分类体系构建，帮助识别各语言语料中的语义空白和冗余。
4. **Diff-In 的样本估值：** 可用于评估多语言数据集中每个样本对模型性能的边际贡献，指导数据采购优先级。
