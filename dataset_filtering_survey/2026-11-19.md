## 🆕 新增论文（4 篇）

### 1. Ambient LLMs: Data-Efficient Supervised Fine-tuning via Temperature Matching

| 字段 | 内容 |
|------|------|
| 作者 | Giannis Daras, Marios Papachristou, Adam Klivans, Antonio Torralba, Constantinos Daskalakis |
| 日期 | 2026-11-17 |
| 链接 | https://arxiv.org/abs/2611.23229 |
| 类别 | **Selection / Sampling** |

**方法摘要：** 当 SFT 训练集远小于预训练数据时，模型容易过拟合并产生灾难性遗忘。本文提出 "Ambient LLMs" 概念，通过温度匹配（temperature matching）技术使微调过程中保留预训练数据分布的尾部特征，从而实现数据高效的 SFT，同时保护模型的泛化能力。

**关键方法：** Temperature Matching, Ambient Distribution Preservation

**实用价值评估：** ⭐⭐⭐（中）
- 对多语言数据集构建的参考价值：当目标语言的 SFT 数据有限时（低资源语言场景），如何避免灾难性遗忘是关键问题。温度匹配方法可能为此提供理论指导。
- 局限：论文聚焦 SFT 阶段，不直接解决预训练数据混合问题。

### 2. Data-Efficient LLM Safety Alignment Guided by Interpretable Features (Less is Safer)

| 字段 | 内容 |
|------|------|
| 作者 | （未列出） |
| 日期 | 2026-11-11 |
| 链接 | https://arxiv.org/abs/2611.16183 |
| 类别 | **Selection / Quality** |

**方法摘要：** 提出 "Less is Safer" (LIS) 方法，利用稀疏自编码器（SAE）的可解释特征来指导安全对齐数据的选择和对 adversarial 样本的合成。仅用 2.4K 样本构建的安全数据集，在安全性和过度拒绝指标上超越了 TRIDENT-Core (26K) 和 WildJailbreak (262K) 等大规模数据集。证明了 SAE 可解释特征能有效指导数据选择。

**关键方法：** SAE-Interpretable Feature-Guided Selection, Adversarial Synthesis, Compact Safety Dataset

**实用价值评估：** ⭐⭐⭐⭐（高）
- 对多语言数据集构建的参考价值：**SAE 特征引导的选择范式可推广到多语言场景**。如果能为不同语言训练 SAE 并提取质量/安全特征，就可以用少量精选数据实现高效对齐，这对低资源语言尤其有价值。
- 此方法已在 baseline 中收录（`cailian_baseline_names.jsonl`），但首次出现在增量报告中。

### 3. LECAT: Measuring LLM Category Learning from Pretraining Data

| 字段 | 内容 |
|------|------|
| 作者 | Jimin Mun, Maarten Sap, Yanai Elazar |
| 日期 | 2026-11-13 |
| 链接 | https://arxiv.org/abs/2611.18419 |
| 类别 | **Quality** |

**方法摘要：** 引入 LeCat 框架，分析 LLM 如何从预训练数据中获取类别知识。研究模型是否学会了组合式类别理解（例如 "airplanes are fast" 能泛化到 "red airplanes" 但不泛化到 "broken airplanes"），提供了预训练数据有效教学的深层洞察。

**关键方法：** Two-Part Category Learning Analysis, Compositional Understanding Measurement

**实用价值评估：** ⭐⭐（低-中）
- 对多语言数据集构建的参考价值：理论性强，主要帮助理解预训练数据的知识传递机制。对多语言场景的启示是：**不同语言中类别知识的分布差异可能影响跨语言迁移效果**，但目前未直接验证多语言场景。
- 适合作为理论参考，不适合直接纳入 pipeline。

### 4. Hidden Cartographer: Hidden State Guided Data Selection for Dual Budgeted Instruction Tuning

| 字段 | 内容 |
|------|------|
| 作者 | Zixuan Qin, Qi Qin, Erbo Li, Ting Wei, Yifan Sun, Zhaoxin Fan |
| 日期 | 2026-10-18 |
| 链接 | https://arxiv.org/abs/2610.23105 |
| 类别 | **Selection** |

**方法摘要：** 在标注成本和训练算力双重预算约束下，提出基于模型隐藏状态的数据选择方法。利用模型内部表征来指导选择最具信息量的指令微调样本，在有限预算内最大化训练效果。

**关键方法：** Hidden State-Guided Selection, Dual Budget Constraints (Annotation + Compute)

**实用价值评估：** ⭐⭐⭐（中）
- 对多语言数据集构建的参考价值：多语言数据标注成本通常高于单语（需要目标语言专家），双预算框架在此场景下有实际意义。隐藏状态引导的方法可作为多语言指令数据选择的候选方案。
- 局限：论文发表于 10 月中旬，可能在下一窗口期被更多引用。

## 📊 趋势洞察

### 本次发现的关键趋势

**1. 数据选择范式：从"难度驱动"到"覆盖度+可解释性"双轨并行**
- "Coverage over Difficulty" 的实证结论持续得到验证（已报告工作的更新版本再次出现）
- SAE 可解释特征引导的数据选择（Less is Safer）代表了新的技术路线：**用模型内部表征而非外部指标来指导选择**
- 隐藏状态引导的选择（Hidden Cartographer）也属于同一趋势

**2. 安全-效率交叉成为稳定方向**
- 本期 2/7 篇论文直接涉及安全对齐数据选择（Safety-Preserving Medical, Less is Safer）
- 安全数据的"少而精"策略（2.4K > 262K）与效率追求高度契合

**3. 数据归因（Data Attribution）向预训练阶段渗透**
- "Data Attribution Should Steer Pretraining" 代表了一个新兴方向：不再只是事后归因，而是**实时用归因结果指导预训练数据调度**
- 与已报告的 influence function 相关工作形成完整链路

**4. 低资源/数据高效场景持续受关注**
- Ambient LLMs 解决 SFT 数据远小于预训练数据时的过拟合问题
- Hidden Cartographer 在双预算约束下优化选择
- 这些都与多语言低资源场景高度相关

### 与之前调研的对比分析

| 维度 | 历史趋势（前 15+ 期报告） | 本期增量 |
|------|--------------------------|----------|
| 热点领域 | 数据选择 > 混合 > 过滤 > 质量 > 去重 | 数据选择仍是绝对主导（5/7） |
| 方法路线 | 梯度/影响力/coreset 三足鼎立 | 模型内部表征（hidden states, SAE）成为新信号源 |
| 安全方向 | 从被动防御到主动威胁建模 | 安全-效率联合优化成为新范式 |
| 工具生态 | 成熟工具（Data-Juicer, NeMo Curator）持续迭代 | 新增工具均为早期实验项目，未形成新竞争 |

### 对多语言数据集构建的启示

1. **SAE 特征引导的多语言数据选择**：如果能为不同语言训练稀疏自编码器，提取语言特异性和语言无关的可解释特征，就可以实现更精准的多语言数据质量控制。这是值得探索的研究方向。

2. **温度匹配保护低资源语言**：Ambient LLMs 的温度匹配方法可能为低资源语言 SFT 提供防止灾难性遗忘的理论工具，值得跟进验证。

3. **覆盖度原则在多语言场景的天然适用性**：Coverage > Difficulty 的结论在多语言场景下尤为重要——确保语言多样性和领域覆盖度可能比追求"高质量"单一样本更重要。

4. **数据归因指导多语言配比**：将数据归因技术应用于多语言预训练，动态调整各语言的数据配比，是一个有前景但实现难度较大的方向。
