### 1. BALIGN: Preference Data Selection for Mitigating the Alignment Tax in Large Language Models

| 字段 | 内容 |
|------|------|
| **作者** | Minsu Kim, Jianxun Lian, Xing Xie, Steven Euijong Whang |
| **年份** | 2026 |
| **链接** | https://arxiv.org/abs/2608.24192 |
| **类别** | Filtering（过滤/筛选） |

**方法摘要：**
本文提出 BALIGN，一种面向偏好优化的平衡数据选择策略，旨在缓解 LLM 对齐过程中的灾难性遗忘（Alignment Tax）。作者通过理论和实验分析偏好优化梯度，识别出三个驱动参数漂移的关键数据特征：(1) 参考模型的 log-probability margin，(2) chosen 与 rejected 响应的 token 长度差，(3) 与通用能力语料的 TF-IDF 相似度。将这三个正交特征聚合为统一的复合风险分数（Composite Risk Score），BALIGN 能系统性地过滤掉高风险偏好样本——即那些破坏模型内在参数或提供极低对齐效用的样本。

**关键方法：**
- Composite Risk Score：三维度正交特征聚合
- 偏好优化梯度分析：理论推导参数漂移的根因
- TF-IDF 相似度过滤：保护通用能力不遗忘

**实用价值评估：** ⭐⭐⭐⭐（高）
- 直接解决对齐训练中的能力退化痛点，对多语言模型尤为重要（多语言能力更易在对齐阶段丢失）
- 计算开销低（仅 TF-IDF + 简单统计特征），可大规模部署
- 与 DPO/ORPO 等主流偏好优化方法兼容，即插即用
- **多语言启示**：可扩展 TF-IDF 相似度度量到多语言场景，用跨语言嵌入替代单语 TF-IDF

### 2. Data Mixing as Mixture Experiment: Response Surface Methodology and Optimal Design for Large Language Model Pretraining

| 字段 | 内容 |
|------|------|
| **作者** | Yicheng Mao, Hongru Du |
| **年份** | 2026 |
| **链接** | https://arxiv.org/abs/2608.23922 |
| **类别** | Mixing（数据混合） |

**方法摘要：**
本文将 LLM 预训练中的数据混合问题重新定义为经典统计学中的混合实验（Mixture Experiment）。在该框架下，数据域对应混合成分，token 份额对应成分比例，proxy 训练运行对应实验设计点，验证 loss 定义概率单纯形上的响应面。作者使用稀疏二阶 Scheffé 响应面模型进行建模，并构造模型鲁棒的 I-optimal 设计用于 proxy 实验。以 RegMix 为案例研究表明，域价值具有强关系性——多个在加性效应下较弱的域通过成对交互（尤其是与 web 文本的组合）变得有利。稀疏 Scheffé 模型在不同模型规模间保持混合排序，并提供加性/交互效应的显式分解。

**关键方法：**
- Scheffé 响应面模型：经典多项式回归适配混合比例约束
- I-optimal design：最小化预测方差的实验设计
- Proxy 实验优化：减少约 25% 的 proxy 运行即可恢复相关混合排序

**实用价值评估：** ⭐⭐⭐⭐⭐（极高）
- **为数据混合提供了首个严格的统计实验设计理论框架**，将此前经验性的 proxy mixing 方法（如 RegMix、RegMix-D）纳入统一理论
- 稀疏 Scheffé 模型可解释性强，能区分加性效应和交互效应——这对理解"为什么某些域组合有效"至关重要
- 减少 25% proxy 运行意味着显著的计算成本节省
- **多语言启示**：直接将语言域视为混合成分，可用该方法优化多语言预训练的语言比例分配，替代目前的网格搜索/随机搜索

### 3. DataRx: Missingness-Aware Sampling for Safer Large Language Model Task-Specific Fine-Tuning

| 字段 | 内容 |
|------|------|
| **作者** | Junbo Zhang, Qianli Zhou, Xinyang Deng, Wen Jiang |
| **年份** | 2026 |
| **链接** | https://arxiv.org/abs/2608.04322 |
| **类别** | Sampling（采样策略） |

**方法摘要：**
本文揭示任务特定微调会削弱已对齐 LLM 的安全护栏这一现象，并提出 DataRx——一种缺失性感知（missingness-aware）的安全数据采样方法。DataRx 基于一个关键假设：当安全样本提供的安全信号能填补模型安全能力的"缺失部分"时，该样本更有效。其核心洞察是利用高维隐藏表征（而非离散 token）量化目标模型原生响应与安全参考响应之间的安全信号缺口。实验表明，仅使用 1% 的额外安全样本（来自 BeaverTails），DataRx 将 Llama3-8B-Instruct 在 7 个下游任务上的平均攻击成功率从随机采样的 59.23% 降至 13.70%。

**关键方法：**
- Missingness-aware sampling：基于安全能力缺口选择样本
- 隐藏表征分析：在隐空间中量化安全信号差距
- 安全信号缺口量化：对比目标模型与安全参考模型的表征差异

**实用价值评估：** ⭐⭐⭐⭐（高）
- 仅 1% 额外安全数据即可实现 4 倍以上的安全性提升，效率极高
- 方法论可迁移——"缺失性感知"思路可用于任何需要保持特定能力的微调场景
- **多语言启示**：多语言微调中安全护栏更易丢失（低资源语言尤为脆弱），DataRx 的隐藏表征方法可扩展到跨语言安全保护

## 📊 趋势洞察

### 本次发现的关键趋势

1. **数据选择从"通用质量过滤"走向"目标感知选择"**
   - BALIGN 和 DataRx 都体现了同一趋势：不再仅基于通用质量指标过滤数据，而是根据**训练目标的特定需求**（保持通用能力 / 填补安全缺口）来选择数据
   - 这与历史报告中观察到的"从离线过滤到在线重加权"的范式转移一脉相承

2. **经典统计理论重新赋能数据工程**
   - Scheffé 响应面模型是 1950s 的经典方法，被创新性地引入 LLM 数据混合
   - 呼应了此前报告中"数据混合方法论持续深化"的趋势，但首次从实验设计理论角度给出严格框架

3. **对齐与安全的数据策划持续升温**
   - 3 篇中有 2 篇直接关注对齐/安全问题（BALIGN 防止能力遗忘、DataRx 保护安全护栏）
   - 延续了近期"对齐数据策划的理论化加速"趋势

### 与之前调研的对比分析

| 维度 | 历史趋势 | 本次发现 |
|------|---------|---------|
| **主导类别** | Selection（数据选择）持续为最大热点 | 3 篇分布在 3 个不同类别，热点趋于分散 |
| **方法论深度** | 经验性方法为主 | 理论化加强（梯度分析、响应面理论、表征空间分析） |
| **对齐关注度** | 持续上升 | 保持高位（2/3 论文与对齐相关） |
| **多语言直接相关** | 每期 1-2 篇 | 0 篇直接面向多语言（但方法论可迁移） |

### 对多语言数据集构建的启示

1. **BALIGN → 多语言对齐保护**：在多语言偏好优化中，可引入"多语言通用能力语料"的 TF-IDF/嵌入相似度特征，防止对齐训练导致低资源语言能力退化
2. **Scheffé 混合实验 → 多语言比例优化**：将语言域视为混合成分，用 I-optimal 设计替代盲目网格搜索来寻找最优语言比例——对 100+ 语言的多语言预训练尤其有价值
3. **DataRx → 多语言安全保护**：多语言微调后的安全退化可能更严重（低资源语言安全数据稀缺），缺失性感知采样可帮助高效分配有限的安全数据预算
